# Quant Agents — 代码审查清单

> 本清单按模块分类，供审查者逐项核对。与 [CODE_REVIEW_STANDARDS.md](./CODE_REVIEW_STANDARDS.md) 配合使用。

---

## 🔍 通用检查 (所有 PR 必须)

- [ ] **描述清晰**：PR 标题和描述能说明变更意图
- [ ] **范围合理**：单 PR 变更 < 500 行（不含测试），大变更已拆分
- [ ] **无调试代码**：无 `print()`、`console.log()`、`breakpoint()` 遗留
- [ ] **无硬编码密钥**：API Key / Token 通过环境变量或配置管理获取
- [ ] **无裸 `except:`**：所有异常处理指定了具体类型
- [ ] **命名规范**：函数、变量、类命名符合项目规范
- [ ] **导入整洁**：无未使用的导入，导入顺序正确
- [ ] **提交信息规范**：commit message 清晰描述变更

---

## 🗄️ 数据层审查 (data_fetcher, data_bus, data_validator)

### 数据获取
- [ ] **多源降级链**：主源失败后能自动降级到备用源
- [ ] **超时设置**：所有外部 HTTP/API 调用设置了合理超时（连接5s，读取30s）
- [ ] **缓存策略**：行情数据有适当的缓存有效期（5分钟），非交易时段返回最近缓存
- [ ] **重试机制**：网络错误有指数退避重试（最多3次）
- [ ] **限流处理**：对数据源限流有合理等待策略
- [ ] **数据为空处理**：返回空 DataFrame/None 时有明确的 fallback 逻辑

### 数据验证
- [ ] **股票代码校验**：输入股票代码经过格式验证（6位数字，符合沪/深/创/科规则）
- [ ] **日期范围校验**：起止日期合法，区间不过大（日频 ≤ 365天）
- [ ] **价格合理性**：价格有基本范围检查（0 < price < 10000）
- [ ] **缺失数据标记**：缺失值用 NaN 而非 0（避免混淆"无数据"和"价格为0"）

### 数据存储
- [ ] **参数化查询**：数据库操作使用参数化查询，杜绝 SQL 拼接
- [ ] **事务管理**：涉及多表写入的操作用事务包裹
- [ ] **连接池**：数据库连接正确管理，无连接泄漏

### 量化专项
- [ ] **复权处理**：历史K线使用前复权（`qfq`），确保回测一致性
- [ ] **交易日历**：日期处理考虑A股交易日历（非每个自然日都是交易日）
- [ ] **除权除息**：分红送股的数据处理逻辑正确

---

## 📊 策略层审查 (signal_extractor, optimizations, portfolio_optimizer)

### 前视偏差 — 第一优先级 🔴
- [ ] **信号计算**：回测中 t 时刻的信号只用 ≤ t 时刻的数据
- [ ] **`shift(0)` 检查**：未在信号计算中使用 `shift(0)` 或 `iloc[-1]`
- [ ] **财报数据**：财务数据按 `pubDate`（发布日期）过滤，而非报告期
- [ ] **复权对齐**：前复权价格用于策略计算，不复权价格仅用于显示

### 回测引擎
- [ ] **手续费**：买入/卖出正确计算佣金（A股：万2.5，最低5元）、印花税（卖出万5）
- [ ] **滑点**：回测中考虑了合理的交易滑点（市场冲击成本）
- [ ] **涨跌停**：正确模拟涨跌停限制下的无法成交情况
- [ ] **停牌**：停牌期间正确跳过，不产生虚假成交
- [ ] **初始资金**：初始资金和后续资金变动的处理正确

### 策略信号
- [ ] **买入信号**：买入条件是 AND 还是 OR 关系，逻辑与文档一致
- [ ] **卖出信号**：止损、止盈、时间止损的优先级关系正确
- [ ] **仓位管理**：单只上限、总仓上限、现金底线的计算和检查正确
- [ ] **信号频率**：信号频率合理（日内频繁切换通常有问题）

### 性能指标
- [ ] **夏普比率**：计算公式正确（无风险利率假设合理）
- [ ] **最大回撤**：从峰值计算，非从初始值计算
- [ ] **年化收益**：考虑了实际交易日数
- [ ] **基准对比**：有合适的基准指数（如沪深300）对比

---

## 🤖 Agent 层审查 (orchestrator, unified_agent, multi_model_voter)

### LLM 调用
- [ ] **超时处理**：LLM API 调用有超时设置（≤ 60s）
- [ ] **重试逻辑**：失败后有合理的重试策略（如指数退避 3 次）
- [ ] **降级策略**：LLM 不可用时有无 LLM 的 fallback 路径
- [ ] **Token 限制**：prompt 长度在模型上下文窗口内
- [ ] **成本控制**：是否记录了每次调用的 token 消耗

### Agent 协作
- [ ] **状态一致性**：多 Agent 之间的状态传递是否正确
- [ ] **死锁预防**：Agent 间通信有无超时兜底，不会无限等待
- [ ] **错误传播**：某个 Agent 失败时，是否会级联导致整个流程崩溃
- [ ] **结果汇总**：多 Agent 结论的融合逻辑是否合理

### 决策记录
- [ ] **决策可追溯**：每次买卖建议记录了完整上下文（输入数据、推理过程、置信度）
- [ ] **复盘数据完整**：决策记录包含后续验证所需的全部字段

---

## 🖥️ 前端审查 (templates/*.html, *.vue, *.ts)

### 组件/模板
- [ ] **Props 类型**：组件 Props 有 TypeScript 类型定义
- [ ] **emit 声明**：emit 事件类型声明完整
- [ ] **响应式正确**：ref/reactive 使用场景正确
- [ ] **计算属性**：复杂计算使用 `computed` 而非方法
- [ ] **组件拆分**：单组件 < 300 行，复杂页面合理拆分

### 数据展示
- [ ] **涨跌颜色**：A股红涨绿跌规范正确
- [ ] **数字格式化**：价格2位小数，涨跌幅2位+%号，成交量/额有千分位
- [ ] **加载状态**：数据加载中有骨架屏或加载动画
- [ ] **空状态**：无数据时有友好的空状态提示
- [ ] **错误状态**：数据获取失败有重试按钮
- [ ] **大列表性能**：超过 100 条数据的列表使用虚拟滚动

### 安全
- [ ] **XSS 防护**：用户输入和动态数据未使用 `v-html`（或已充分消毒）
- [ ] **敏感信息**：API Key 等敏感信息不出现在前端代码中

### 性能
- [ ] **无内存泄漏**：定时器、WebSocket 在 `onUnmounted` 中正确清理
- [ ] **图片优化**：大图使用懒加载
- [ ] **打包大小**：无意外引入的大型依赖

---

## 📈 报告层审查 (report_generator, email_report)

### 报告生成
- [ ] **数据正确性**：报告中的数字与数据源一致
- [ ] **格式一致性**：日期、金额、百分比格式统一
- [ ] **异常标记**：异常数据（极端涨跌、异常成交量）有醒目标记
- [ ] **HTML 安全**：生成的 HTML 无 XSS 风险

### 邮件发送
- [ ] **凭据安全**：SMTP 密码从环境变量读取
- [ ] **发送失败处理**：发送失败有日志记录和告警
- [ ] **附件管理**：附件大小合理（≤ 10MB），过期清理

---

## 🔧 配置与部署审查

### 配置管理
- [ ] **外部化**：环境相关的配置通过环境变量或配置文件管理
- [ ] **默认值合理**：所有配置有安全的默认值
- [ ] **验证**：启动时有配置检查（ConfigManager.validate()）

### 依赖管理
- [ ] **版本锁定**：关键依赖有版本范围限制
- [ ] **无冗余依赖**：未使用的包已从依赖列表中移除
- [ ] **安全审计**：无已知漏洞的依赖版本

### 部署
- [ ] **向后兼容**：配置变更、API 变更有迁移说明
- [ ] **健康检查**：服务有 `/health` 或等效的健康检查端点
- [ ] **日志**：关键操作有 INFO 级别日志，错误有 ERROR 级别日志
