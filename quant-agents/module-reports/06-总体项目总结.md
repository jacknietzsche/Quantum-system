## 四、关键发现与洞察

### 4.1 A 股量化交易的范式差异

从多个项目的回测和研究结论来看，A 股市场呈现与美股显著不同的特征：

1. **技术因子全部负 IC**（QuantLLM 实证）：A 股趋势跟踪策略无效，均值回复/反转策略更有效
2. **多空辩论比单 Agent 更有效**（TradingAgents-AShare 验证）：辩论机制显著提升决策质量
3. **YAML 即策略**（daily_stock_analysis 创新）：将策略参数化为配置文件，无需编码
4. **本地优先**：A 股 AI Agent 更倾向于本地部署，而非云 API
