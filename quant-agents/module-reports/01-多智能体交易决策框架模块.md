## 一、模块概述

本模块聚焦于基于 **LangGraph 多智能体编排** 的金融交易决策框架，包含 3 个同源项目，均源自 [TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents)（arXiv:2412.20138），形成从原版 → 中文增强 → A股特化的演进链条。

## 二、核心架构分析

### 2.1 通用流水线模式

三个项目共享相同的多智能体协作流水线架构：

```
用户输入
    ↓
意图解析器 (Intent Parser)
    ↓
数据采集器 (Data Collector)
    ↓
┌─── 分析师团队（并行）───┐
│  基本面 │ 技术面 │ 新闻  │
│  情绪 │ 宏观 │ 资金流  │
└────────────────────────┘
    ↓
┌─── 研究员团队（多空辩论）─┐
│  多头研究员 vs 空头研究员  │
│  研究总监（综合裁决）      │
└───────────────────────────┘
    ↓
交易员（生成执行方案）
    ↓
┌─── 风控团队（三方讨论）───┐
│  激进 │ 保守 │ 中性       │
└───────────────────────────┘
    ↓
组合经理（最终裁决）→ 交易信号/研报
```

## 三、技术亮点

### 3.1 辩论机制（核心创新）

三个项目均实现多轮辩论机制，但深度不同：

- **原版**：看涨/看跌研究员各输出 1 轮观点，研究经理裁决
- **CN版**：支持 `max_debate_rounds` 可配置辩论轮次，可多轮交锋
- **AShare版**：Agent 卡片点击展开辩论抽屉，**Token 级流式呈现**辩论过程，用户可实时观看对抗

### 3.2 LangGraph 状态图编排

所有项目使用 LangGraph 的 `StateGraph` 构建有向图工作流：

```python
# 伪代码模式
graph = StateGraph(AgentState)
graph.add_node("analysts", analyst_team)
graph.add_node("researchers", research_team)
graph.add_node("trader", trader_agent)
graph.add_node("risk", risk_team)
graph.add_edge("analysts", "researchers")
graph.add_edge("researchers", "trader")
graph.add_edge("trader", "risk")
graph.set_entry_point("analysts")
```

### 3.3 决策记忆系统

- **原版**：将历史决策持久化到磁盘，下次分析注入反思信息
- **CN版**：基于 ChromaDB 的 `FinancialSituationMemory`，支持语义检索历史决策
- **AShare版**：数据库持久化历史研报，按标的/日期检索

## 四、适用场景对比

## 五、局限与改进方向

| 局限 | 说明 | 改进方向 |
|------|------|---------|
| 实盘交易 | 三个项目均仅输出信号建议 | 接入券商 API（如 xtquant）实现自动执行 |
| 因子研究 | 无量化因子挖掘能力 | 融合 RD-Agent 的因子自动发现 |
| 投资哲学深度 | Agent 思维模式单一 | 注入 Buffett/Munger/Taleb 技能知识 |
| 数据源 | 依赖免费数据源（AKShare/BaoStock） | 接入量化平台数据服务 |
| 回测系统 | 基础回测，缺乏专业级 | 集成 backtrader/qlib 回测引擎 |
