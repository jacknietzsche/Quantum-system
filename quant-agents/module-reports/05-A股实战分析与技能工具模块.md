## 二、核心架构分析

### 2.1 daily_stock_analysis：完整 A 股分析系统

**架构**：混合模块化 + AI Agent 核心

```
┌────────────────────────────────────────────────────┐
│                  用户入口                            │
│  GitHub Actions / Docker / CLI / WebUI / FastAPI    │
└─────────────────────┬──────────────────────────────┘
                      ↓
┌────────────────────────────────────────────────────┐
│              分析流水线                              │
│  策略选择（11 种 YAML 策略） → 数据采集 → AI 分析   │
│  → 多维评分 → 决策看板                              │
└──────────┬──────────┬──────────┬───────────────────┘
           ↓          ↓          ↓
    ┌──────────┐ ┌──────────┐ ┌──────────┐
    │ 技术面   │ │ 基本面   │ │ 情绪面   │
    │ 指标计算 │ │ 财务分析 │ │ 新闻分析 │
    └──────────┘ └──────────┘ └──────────┘
           ↓
    ┌─────────────────────────────────────┐
    │              输出层                   │
    │  决策仪表盘 / 回测验证 / Agent Q&A    │
    │  多渠道推送（企微/飞书/Telegram/邮件） │
    └─────────────────────────────────────┘
```

| `wave_theory.yaml` | 波浪理论 | 技术框架 |
| `emotion_cycle.yaml` | 情绪周期 | 情绪 |

| `volume_breakout.yaml` | 放量突破 | 量价 |
| `shrink_pullback.yaml` | 缩量回踩 | 量价 |
| `box_oscillation.yaml` | 箱体震荡 | 形态 |

**技术特点**：
- 支持 6+ 种 AI 模型（AIHubMix/Gemini/DeepSeek/Qwen/Claude/Ollama）
- 7 种数据源（TickFlow/AKShare/Tushare/PTrade/BaoStock/YFinance/Longbridge）

- 多市场覆盖（A股/港股/美股/ETF）
- 策略为 YAML 形式，用户可自定义

### 2.3 qingfeng-skills：可转债分析

**流水线**：
```
集思录数据获取 (data_fetcher.py)
    → 智能过滤 (data_filter.py) → 默认"三低优化策略"
    → AI 决策分析 (ai_analyzer.py)
    → 报告输出（JSON + Markdown）
```

**过滤参数**：

| 参数 | 默认模式 | 严格模式 |
|------|---------|---------|
| 最高转债价格 | 150 元 | 120 元 |
| 最高转股溢价率 | 50% | 30% |
| 最大剩余规模 | 50 亿 | 30 亿 |
| 排除强赎公告 | ✅ | ✅ |
| 排除 ST 正股 | ✅ | ✅ |

### 2.4 china-stock-research-skills：全栈研究工作流

**6 个可组合核心模块**：

```
父编排器（Orchestrator）
    → 识别分析模式
    → 路由到对应模块
    → 合并输出

├── strategy-business-transition    业务战略与转型
├── business-decomposition-order-quality  业务分解与订单质量
├── financial-health                财务健康评估
├── industry-competition-moat       行业竞争与护城河
├── risk-warning-catalysts          风险预警与催化剂
└── valuation-investment-strategy   估值与投资策略
```

**设计原则**：
- Evidence First：每项结论必须有公开数据源
- 分层输出：Fact → Interpretation → Open Questions
- 官方来源优先：财报>公告>新闻>第三方
- 6 种行业覆盖模板：周期/医疗/消费/重资产/出口/项目订单

### 2.5 report-reader：财报解读

**四轮递进式解读流程**：

```
Round 1: 业务理解（收入构成/产品结构/毛利率）
Round 2: 财务三表拆解（利润表/资产负债表/现金流量表）
Round 3: 管理层话语分析（MD&A 措辞变化）
Round 4: 研报交叉验证（可选，对比券商研报）
    → 可视化信息图（HTML+Playwright 截图 → PNG）
    → 结构化 Markdown 报告
```

## 三、技术亮点

### 3.1 daily_stock_analysis 的策略即配置

策略以 YAML 格式定义，自然语言描述规则，无需编码：

```yaml
# strategies/ma_golden_cross.yaml
name: 均线金叉
category: trend
required_tools:
  - kline
  - ma
core_rules:
  - "5日均线上穿10日均线"
  - "成交量大于5日均量"
market_regimes:
  - bull
  - sideways
```

用户可通过 `AGENT_SKILL_DIR` 环境变量添加自定义策略。

### 3.2 china-stock-research 的"有源可查"原则

所有模块输出必须包含来源链接，技术实现上包含：
- 统一 Source Registry（来源注册表）
- Company Disclosure Map（公司披露映射）
- 标准化 Citation 格式

### 3.3 a-share-skill 的短线交易框架标准化

"推哥"系统将所有短线场景统一为结构化输出：

```json
{
  "trigger": "触发条件",
  "invalidation": "失效条件",
  "risk": "风险提示",
  "position_grade": "仓位等级（1-5）"
}
```

### 3.4 report-reader 的财报可视化

- HTML 模板 → Playwright 截图 → 专业级财报速查卡 PNG
- 30 秒可回原文核对（标注年报页码）

## 五、局限与改进方向

| 项目 | 主要局限 | 改进方向 |
|------|---------|---------|
| daily_stock_analysis | 依赖较多第三方 API；前端较简单 | 集成 TradingAgents-CN 前端；增加本地缓存层 |

| report-reader | 需 PDF 输入，无法自动获取财报 | 集成财报自动下载通道 |
