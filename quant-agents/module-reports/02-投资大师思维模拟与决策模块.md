## 一、模块概述

本模块聚焦于 **投资大师思维模拟** 与 **投资哲学知识注入**，包含 1 个 Agent 项目 + 3 个 Skill 项目。核心理念是利用 LLM 模拟著名投资大师（巴菲特、芒格、塔勒布等）的决策逻辑，为投资分析提供多元视角。

## 三、技术亮点

### 3.1 大师思维的层级注入

```
┌─────────────────────────────────────┐
│  Layer 1: 核心心智模型              │
│  （5-6 个不可约减的思维框架）        │
├─────────────────────────────────────┤
│  Layer 2: 决策启发式                │
│  （8-9 条可执行的决策规则）          │
├─────────────────────────────────────┤
│  Layer 3: 表达 DNA                  │
│  （语言风格、措辞习惯、修辞模式）    │
├─────────────────────────────────────┤
│  Layer 4: 参考知识库                │
│  （行业手册/研究报告/案例分析）      │
└─────────────────────────────────────┘
```

### 3.2 ai-hedge-fund 的技术差异化

1. **角色模拟深度**：每位大师 Agent 有独立的系统提示词，包含该投资者的核心投资理念、分析方法、决策偏好
2. **信号汇聚机制**：所有 Agent 输出统一 JSON 格式信号（买入/卖出/持有 + 仓位比例建议）
3. **风险约束层**：风险管理 Agent 独立于分析师，确保仓位不越限
4. **v2 量化转型**：新一代架构转向基于原则的量化流水线，包含事件研究框架、CPCV 验证、Almgren-Chriss 市场冲击模型

### 3.3 Skill 项目的渐进式加载设计

```yaml
# buffett-skills 的三级分派逻辑
A. 快速筛选 → 8 问检查表（无需读文件）
B. 深度分析 → 顺序读取 护城河→管理层→财务→估值
C. 专题问题 → 直接跳转对应参考文件
```

这种设计使得技能包可以处理从快速筛选到深度研究的全频谱场景，同时避免不必要的文件加载。

## 五、局限与改进方向

| 项目 | 主要局限 | 改进方向 |
|------|---------|---------|
| ai-hedge-fund | 仅支持美股；大师模拟深度有限；无持久化 | 扩展 A 股数据源；加深角色提示词工程 |
| buffett-skills | 无独立执行能力；过于依赖 AI 理解 | 增加可执行的检查表和评分卡 |
| munger-skill | 参考文件较少；跨学科覆盖不够广 | 补充更多学科的思维模型 |
| taleb-skill | 偏重理论；实操建议较少 | 增加杠铃策略的具体配置案例 |
