# 四轮递进式 Prompt 模板

每轮 prompt 都要求 AI 标注数据出处页码，这是最简单的防幻觉手段。

---

## 第一轮：业务理解（5 分钟）

### Prompt 1：公司靠什么赚钱

```
我不是财务专业人士，但我在考虑投资这家公司。请基于这份年报，用最通俗的语言回答：

1. 这家公司靠什么赚钱？不同业务各贡献了多少收入和利润？
2. 哪块业务在增长，哪块在萎缩？增速分别是多少？
3. 各业务线的毛利率分别是多少？哪块最赚钱？
4. 主要销售渠道是什么？直销和经销各占多少？
5. 国内和海外的收入占比？

请用大白话解释所有财务术语。每个数据请注明年报页码。
```

### 使用建议

- 先问业务，不要上来就问财务指标
- 关注：哪块是现金牛、哪块是增长引擎
- 毛利率是判断盈利能力的核心指标
- 增长靠提价还是靠放量，是重要信号

## 第二轮：财务三表拆解（15 分钟）

### Prompt 2a：利润表 — 赚钱效率

```
请对比这份年报中最近两年的利润表数据，回答：

1. 营业收入增长了多少？归母净利润增长了多少？两者是否同步？
2. 毛利率和净利润率分别是多少？同比怎么变化？
3. 各项费用（销售费用、管理费用、研发费用、财务费用）的增速跟收入增速比，哪些在变大？
4. 如果利润率下降了，主要原因是什么？

请用大白话解释所有财务术语。每个数据请注明年报页码。
```

**关键判断**：
- 收入和利润同步增长 → 健康
- 销售费用增速远超收入增速 → 花更多钱维持增长，需警惕趋势
- 财务费用为负 → 账上现金多，利息收入 > 利息支出

### Prompt 2b：资产负债表 — 有没有雷

```
请分析这份年报的资产负债表，回答：

1. 总资产和总负债分别是多少？资产负债率是多少？
2. 有没有大额的商誉、应收账款、存货？同比变化多少？
3. 货币资金和类现金资产有多少？占总资产比例多少？
4. 有没有有息负债（短期借款、长期借款、应付债券）？
5. 合同负债（预收款）跟去年比变化多大？

请用大白话解释所有财务术语。每个数据请注明年报页码。
```

**关键判断**：
- 资产负债率低 + 现金多 → 财务结构健康
- 商誉高 → 并购多，有减值风险
- 应收账款暴涨 → 可能卖了货但收不到钱
- 存货需要结合行业判断（茅台存货增长是好事，一般公司可能是坏消息）
- 合同负债下降 → 经销商备货意愿减弱，先行指标

### Prompt 2c：现金流量表 — 利润真假

```
请分析这份年报的现金流量表，回答：

1. 经营活动产生的现金流量净额是多少？跟净利润差距大吗？
2. 过去两到三年的经营现金流趋势是什么？
3. 投资活动现金流的主要去向是什么？
4. 筹资活动现金流是净流入还是净流出？主要因为什么？

请用大白话解释所有财务术语。每个数据请注明年报页码。
```

**关键判断**：
- 经营现金流 ≥ 净利润 → 利润含金量高
- 经营现金流远低于净利润甚至为负 → 高度警惕，利润可能有水分
- 连续多年经营现金流覆盖净利润 → 非常健康的信号

## 第三轮：管理层话语分析（5 分钟）

### Prompt 3：读出没说出口的话

```
请分析这份年报中"管理层讨论与分析"部分，回答：

1. 管理层对未来的预期是乐观还是谨慎？依据是什么？
2. 下一年的经营目标（营收增速、利润增速等）是什么？跟今年实际增速比是加速还是减速？
3. 管理层提到了哪些风险？哪些风险是今年新增提到的？
4. 有没有哪些措辞看起来在回避具体问题？
5. 公司在股东回报（分红、回购）方面有什么新动作？
6. 管理层对公司战略的描述有没有发生变化？比如是否在强调新的业务方向？

请用大白话解释。每个结论请注明年报页码。
```

### 进阶 Prompt 3+：两年年报对比（如果有两年的年报）

```
我同时上传了这家公司连续两年的年报。请对比两年的"管理层讨论与分析"部分：

1. 措辞和重点有什么变化？
2. 有没有去年提到但今年不再提的话题？
3. 有没有今年新增的说法或表述？
4. 经营目标的口径有没有变化（比如从"力争增长"变成"稳定增长"）？
5. 风险提示的排序和权重有没有变化？

请分别注明两年的页码。
```

**关键判断**：
- 增速目标从两位数降到个位数 → 管理层在给预期打预防针
- 新增"周期""转型"等措辞 → 高增长阶段可能告一段落
- 开始强调"生活方式""生态"等新叙事 → 核心产品量增空间可能遇到天花板
- 分红和回购力度加大 → 管理层认为股价被低估，或增长放缓后用回报留住股东

## 第四轮：研报交叉验证（可选，5 分钟）

### Prompt 4：检验研报

```
我同时上传了这家公司的最新年报和一份券商研究报告。请对比以下方面，并注明各自的数据出处页码：

1. 研报中的核心结论（评级、目标价、增长预期）是否有年报数据支撑？
2. 研报中有没有选择性忽略年报中披露的风险因素？
3. 研报对公司前景的乐观程度，与年报中管理层自己的表态是否一致？
4. 研报预测的前提假设是什么？这些假设合理吗？
5. 研报强调的利好因素，在年报数据中是否真的那么强？
```

**关键判断**：
- 研报预测增速 > 管理层目标 → 券商假设公司会"超额完成"，需判断合理性
- 研报大篇幅讲利好但忽略关键风险信号 → 选择性偏差
- 增长驱动是"卖更多"还是"卖更贵" → 研报是否准确描述了增长来源
- 研报不是在骗你，但分析师会选择强调利好、淡化隐忧

---

## 通用追问技巧

- 遇到任何术语不懂：`"用一句大白话解释{术语}"`
- 想深挖某个数字：`"能展开说说{某指标}变化的原因吗？"`
- 想看原始数据：`"请列出{某张表}的完整数据，不要总结"`
- 想对比同行：`"这个{指标}在行业内是什么水平？"`
