# 财报信息图设计指南

信息图的目标是：让用户在 10 秒内抓住这家公司最关键的财务特征——而概要叙事是这张图的灵魂。

## 0. 概要叙事写作指南（信息图灵魂）

概要叙事是信息图中**最重要的一段文字**。它不是摘要，不是数据罗列，而是「数字背后的故事」。用户只读这段话，就能抓住核心判断。

### 结构（200-400 字）

按以下四段式结构撰写：

**第一段：硬数据开场（1-2 句）**

用最关键的 2-3 个数字定调。数字要具体，要有画面感。

```
✗ 茅台2024年业绩稳健增长，营收和利润均实现两位数增长。
✓ 茅台2024年报，营收1709亿，利润862亿，ROE 36%。数字很漂亮。
```

**第二段：转折信号（2-4 句）**

哪些硬数据在敲警钟？每个信号用一句话讲清楚「是什么 + 为什么重要」。不要超过 3 个信号，挑最能改变判断的。

```
✗ 费用增长较快，合同负债有所下降，需要关注。
✓ 合同负债下降32%。这是经销商提前打款，下降幅度远超同期收入增速，
  说明渠道信心在减弱，提前备货意愿明显下降。
```

**第三段：管理层潜台词（1-2 句）**

管理层在做什么？真实意图是什么？是真金白银还是口头安抚？不要复述管理层原话，要翻译成大白话判断。

```
✗ 管理层加大了分红力度并启动了股份回购计划。
✓ 管理层在安抚市场。加大分红力度，首次启动回购——真金白银，
  但踩着下限，力道有限，更多是防守而非进攻。
```

**第四段：一句话结论（1 句）**

最核心的判断，要有立场。不是「有好有坏」的骑墙话，而是明确的、可行动的判断。

```
✗ 茅台基本面仍然较好，但需关注部分指标变化。
✓ 茅台基本面仍然极强，但合同负债和销售费用增速，
  是判断景气度最重要的两个先行指标，需要逐季跟踪。
```

### 写作禁忌

| 禁止 | 原因 | 替代 |
|------|------|------|
| AI 文案腔（赋能、全方位、多维） | 一看就是 AI 写的 | 用具体动词和数据 |
| 空洞形容词（稳健增长、持续向好） | 没有信息量 | 说具体数字和变化 |
| 骑墙（既有机遇也有挑战） | 没有判断 | 给明确立场 |
| 超过 400 字 | 信息图不是文章 | 砍到最硬的判断 |
| 空口结论 | 不可信 | 每个判断配数据 |
| 连续三句以上都是正面或都是负面 | 失去张力 | 正反交叉，制造节奏 |

### 语气参考

好的概要叙事读起来像一位有经验的投资者在跟朋友聊天——有数据、有判断、有态度，但不装腔作势。

### 在信息图中的位置

概要叙事放在标题区和数据区之间，用上下粗线框定，使用衬线字体（`var(--serif)`），字号 32px，行高 1.75。关键数字用 `<strong>` 标注，自动渲染为弹点色。

```html
<div class="narrative">
  <p>茅台2024年报，营收<strong>1709亿</strong>，利润<strong>862亿</strong>，ROE <strong>36%</strong>。数字很漂亮。……</p>
</div>
```

## 1. 内容选择原则

信息图不是报告全文的可视化。它是一张「速查卡」。

### 必选内容（锚点）

从解读报告中提取以下核心数据点：

| 类别 | 指标 | 说明 |
|------|------|------|
| 身份 | 公司名称 + 年份 | 标题区 |
| 规模 | 营业收入 | 公司体量 |
| 盈利 | 归母净利润 + 净利润率 | 赚钱能力 |
| 增长 | 营收增速 + 利润增速 | 成长性 |
| 质量 | 经营现金流 / 净利润 | 利润含金量 |
| 安全 | 资产负债率 | 财务风险 |
| 信号 | 1-2 个最关键的发现 | 合同负债变化、费用趋势等 |

**总量控制在 ≤ 8 个数据指标 + 3-5 条文字发现。**

### 禁止内容

- 不要放完整的财务报表
- 不要放逐项费用明细
- 不要放大段文字分析
- 不要放所有业务线的完整数据

## 2. 色调选择

财报信息图默认使用「商业」色调，但可根据公司特征调整：

| 公司特征 | 推荐色调 | 理由 |
|----------|---------|------|
| 传统行业（白酒、食品） | 温暖 `--bg: #F7F4EF; --green: #C8B898; --pink: #C17F4E` | 人文感、品牌感 |
| 科技/互联网 | 技术 `--bg: #F0F3F7; --green: #8EAAB8; --pink: #1A936F` | 数据感、现代感 |
| 金融/银行 | 商业 `--bg: #F4F3F0; --green: #A8A498; --pink: #2D6A4F` | 稳重、专业 |
| 医药/科研 | 科研 `--bg: #F2F6F4; --green: #7DAE96; --pink: #D68C45` | 研究感、发现感 |
| 周期/资源 | 锐利 `--bg: #EDEDF0; --green: #6E6E80; --pink: #D93025` | 风险感、波动感 |

## 3. 布局模式

### 推荐结构：层级 + 并列混合

财报信息图天然是「层级」结构（总览 → 分项 → 信号），但分项之间适合用「并列」排布。

**推荐布局**（从上到下）：

```
┌──────────────────────────────┐
│  标题区                       │
│  公司名称 · 2024年报解读       │
├══════════════════════════════┤
│  概要叙事（200-400字）         │
│  数字背后的故事，有态度的判断   │
│  衬线字体，关键数字用弹点色    │
├══════════════════════════════┤
│  核心指标卡片（2-3 个大数字）   │
│  ┌──────┐  ┌──────┐  ┌──────┐│
│  │ 营收  │  │ 净利润 │  │ 增速  ││
│  │1709亿 │  │ 862亿 │  │+15.7%││
│  └──────┘  └──────┘  └──────┘│
├──────────────────────────────┤
│  业务结构（占比可视化）         │
│  ████████████░░░ 茅台酒 85%   │
│  ███░░░░░░░░░░░ 系列酒 15%   │
├──────────────────────────────┤
│  关键信号（2-3 条发现）        │
│  ⚡ 合同负债下降32%           │
│  ⚡ 销售费用增速超收入增速     │
│  ⚡ 经营现金流 > 净利润       │
├──────────────────────────────┤
│  [colophon]                   │
└──────────────────────────────┘
```

### 布局规则

- 核心指标用大字（80-120px），等宽字体
- 业务占比用 CSS 实现的水平条形图（不用外部图表库）
- 关键信号用弹点色（`--pink`）标注，每条一行
- 标题区左对齐，不要居中
- 指标卡片不要等分——最重要的那个占更大空间

## 4. 数据可视化

### 只用纯 CSS 实现

不要引入 Chart.js 或 D3.js。所有图表用 CSS 实现：

**水平条形图**（业务占比）：
```css
.bar {
  height: 28px;
  border-radius: 14px;
  background: var(--green);
}
.bar-label {
  font: 500 28px/1 var(--mono);
}
```

**指标卡片**：
```css
.metric-value {
  font: 700 96px/1 var(--mono);
  color: var(--ink);
}
.metric-label {
  font: 400 28px/1.4 var(--sans);
  color: var(--ink-light);
}
```

**趋势箭头**（用 CSS 三角形或 Unicode 箭头）：
- 增长：`▲` 用绿色
- 下降：`▼` 用弹点色
- 持平：`●` 用灰色

## 5. 字号规范（手机端优化）

1080px 画布在手机上缩放约 2.8 倍，字号必须足够大：

| 元素 | 最小字号 | 推荐字号 |
|------|---------|---------|
| 标题 | 64px | 80-96px |
| 核心数字 | 72px | 96-120px |
| 副标题 | 32px | 36-40px |
| 正文 | 36px | 36-40px |
| 标注 | 24px | 28-32px |
| 来源/页码 | 20px | 22-24px |

## 6. 自检清单

生成 HTML 后、截图前，逐项确认：

- [ ] 是否只放了 ≤ 8 个核心指标？（没有放完整报表）
- [ ] 是否有 1-2 个让人第一眼就被抓住的大数字？
- [ ] 色调是否与公司行业特征匹配？
- [ ] 弹点色是否只用于标注关键信号（≤ 3 处）？
- [ ] 所有数字是否来自年报原文（不是 AI 编造的）？
- [ ] 手机端可读性：正文 ≥ 36px？标注 ≥ 24px？
- [ ] 是否避免了三等分等宽卡片？
- [ ] 标题是否左对齐（非居中 Hero）？
