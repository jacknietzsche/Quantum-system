# 数据核对清单与防幻觉指南

## 1. AI 读财报的常见错误

| 错误类型 | 表现 | 频率 |
|----------|------|------|
| 数字提取错误 | 跨行合并表格中的数字读错、单位混淆（万/亿） | 高 |
| 页码标注错误 | 标注的页码与实际内容不对应 | 中 |
| 计算错误 | 百分比、同比增速算错 | 中 |
| 张冠李戴 | 把去年的数据当成今年的 | 低 |
| 捏造数据 | 编造年报中不存在的数字 | 低 |

## 2. 必须核对的核心数据

以下数据务必回年报原文逐项核对，不要信任 AI 的提取结果：

### 利润表
- [ ] 营业收入（确认单位：亿元/万元）
- [ ] 归母净利润
- [ ] 营收同比增速（自己算一遍：今年/去年-1）
- [ ] 净利润同比增速
- [ ] 毛利率 = (营收-营业成本)/营收
- [ ] 净利润率 = 归母净利润/营收

### 资产负债表
- [ ] 总资产、总负债
- [ ] 资产负债率 = 总负债/总资产
- [ ] 货币资金
- [ ] 存货（注意：有些公司存货单位是万元，不是亿元）
- [ ] 应收账款
- [ ] 商誉
- [ ] 合同负债

### 现金流量表
- [ ] 经营活动现金流净额
- [ ] 投资活动现金流净额
- [ ] 筹资活动现金流净额

## 3. 防幻觉技巧

### 强制页码引用
每个 prompt 都加上：「每个数据请注明年报页码。」AI 给了页码，花 30 秒翻到原文就能核对。没给页码的结论多留个心眼。

### 交叉验证
- 同一个数字至少在年报中出现两次（正文 + 财务报表附注），两处应该一致
- 增速自己算一遍，不要直接用 AI 给的数字
- 百分比和绝对额互相验证：营收 × 毛利率 ≈ 毛利额

### 单位检查
- 年报中的数字单位可能是「元」「万元」「亿元」，注意区分
- AI 经常混淆万元和亿元，这是最高频的错误
- 核对方法：看报表表头的单位标注

### 上下文检查
- AI 可能会把「2023年」的数据标注为「2024年」
- 核对方法：确认数据所属的会计期间

## 4. 年报关键章节速查

| 章节 | 通常位置 | 包含内容 |
|------|---------|---------|
| 重大事项提示 | 目录前几页 | 分红方案、回购计划 |
| 主要会计数据 | 第 5-8 页 | 收入、利润、现金流三年对比 |
| 董事会报告 | 第 8-20 页 | 业务分析、行业展望 |
| 经营情况讨论与分析 | 第 15-25 页 | MD&A，管理层话语 |
| 财务报表 | 第 30-80 页 | 三张表 + 附注 |
| 股东变动 | 靠近末尾 | 前十大股东变化 |

> 注：页码范围因公司而异，仅供参考。

## 5. 术语大白话对照表

| 财务术语 | 大白话解释 |
|----------|-----------|
| 毛利率 | 每卖100块钱，扣掉直接成本后还剩多少 |
| 净利润率 | 每卖100块钱，扣掉所有成本和税费后真正赚到多少 |
| 资产负债率 | 100块钱的家当里，有多少是借来的 |
| 商誉 | 买别的公司时多付的那部分钱（买贵了的部分） |
| 合同负债 | 客户提前付的钱，还没交货（预收款） |
| 经营现金流 | 做生意真正收到的现金（不是纸面上的利润） |
| 有息负债 | 需要付利息的借款（银行贷款、债券等） |
| 归母净利润 | 属于母公司股东的净利润（扣掉少数股东权益后） |
| 应收账款 | 卖了货但还没收到的钱 |
| 存货周转天数 | 从进货到卖出去平均需要多少天 |
