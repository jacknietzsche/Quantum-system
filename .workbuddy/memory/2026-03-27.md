## 代码审查机制建立 (2026-03-27 21:30)

### 问题诊断
- **文件**: dashboard_v15.py
- **错误**: ValueError: 'a' cannot be empty unless no samples are taken
- **位置**: 第 151 行 `np.random.choice(dates[20:-5], ...)`
- **原因**: 用户选择的日期范围过短，导致 `dates[20:-5]` 切片返回空数组

### 解决方案
1. **添加长度检查**: 最小需要 25 个交易日（20天预热 + 5天缓冲）
2. **防御性编程**: 
   ```python
   min_required_days = 25
   if len(dates) < min_required_days:
       trade_dates = []
   else:
       available_dates = dates[20:-5]
       if len(available_dates) == 0:
           trade_dates = []
       else:
           trade_dates = np.random.choice(available_dates, ...)
   ```
3. **用户提示**: 添加 Streamlit warning 提示用户日期范围太短
