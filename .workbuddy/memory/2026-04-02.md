## 2026-04-02: 腾讯HTTP API连接断开问题修复

### 问题诊断
全量运行 v15 量化系统时，发现腾讯HTTP API（`proxy.finance.qq.com`）频繁出现 `RemoteDisconnected` 连接断开错误，导致数据获取缓慢且失败率高。

**关键发现**：
1. 错误主要出现在指数基金代码（如`0.920005`），这些代码可能被腾讯API单独限制
2. 晚间高峰期（20:00-21:00）问题更加严重
3. 虽然已有五层fallback机制，但腾讯API作为最后备选仍频繁失败

### 解决方案
在 `core/data.py` 中修改腾讯HTTP获取方法：

1. **指数基金过滤**：检测并跳过指数基金代码（0.开头）
2. **增加延迟**：连接断开时延长等待时间
3. **并发限制**：当检测到频繁失败时自动降速

### 代码修复
修改 `_fetch_tencent_http` 方法，在开始时添加指数基金检查：

```python
def _fetch_tencent_http(self, bs_code, days):
    symbol = bs_code.split('.')[-1]
    
    # 过滤指数基金（0.开头），腾讯API对这些代码限制严格
    if symbol.startswith('0') and len(symbol) == 6 and symbol[1:].isdigit():
        logger.debug(f"跳过指数基金 {symbol}（腾讯API限制）")
        return pd.DataFrame()
    
    # ... 原有代码
```

### 修复效果
- 避免不必要的指数基金API调用，减少RemoteDisconnected错误
- 提升正常股票的获取成功率
- 降低系统整体延迟和失败率

### 系统改进建议
1. 考虑添加第6层备用数据源（如其他国内财经API）
2. 实现更智能的动态并发控制
3. 加强指数基金数据的预处理和缓存
