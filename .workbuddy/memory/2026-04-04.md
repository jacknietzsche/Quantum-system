## 模拟交易报告系统 V2 开发

### 新增文件
1. **simulation_signals.py** - 买卖信号生成模块
2. **simulation_portfolio.py** - 仓位管理模块
3. **core/report.py** - 新增 SimulationReportGenerator
4. **run_simulation_v2.py** - 主入口脚本

### 核心功能
- 交易信号：评级(A-E)、信心度、止盈止损价、目标仓位
- T+1交易模式：今晚分析 -> 明早开盘买入 -> 明晚更新评估
- 仓位管理：基于评分分配仓位（最高15%）

### 使用方法
```bash
python run_simulation_v2.py --only-report  # 生成报告
python run_simulation_v2.py --date 20260404  # 指定日期
python run_simulation_v2.py --capital 200000  # 自定义资金
```

### 报告位置
- simulation_portfolio/reports/sim_report_YYYYMMDD.html

### 融合报告功能（新增）
1. **unified_report.py** - 融合报告生成器
2. 将量化选股报告 + 模拟交易报告整合为统一报告
3. 报告结构:
   - Part 1: 绩效概览卡片（收益/回撤/胜率/持仓/现金）
   - Part 2: 量化选股推荐（评分详情、因子状态、见顶风险）
   - Part 3: 模拟交易信号（买入/卖出评级、止盈止损、目标仓位）
   - Part 4: 当前持仓状态（盈亏分析、止损止盈建议）
   - Part 5: 净值曲线 & 回撤图表

4. 报告位置:
   - unified_report_YYYYMMDD.html（融合报告）
   - sim_report_YYYYMMDD.json（原始数据）

### 专业报告改进（第三轮：参考顶尖量化公司）
