## 降级链重新设计（针对日频策略）

### 原降级链（已过时）
```json
"fallback_chain": [
    "akshare",
    "tencent",
    "sina",
    "efinance",
    "baostock",
    "tickflow"
]
```

**问题**：
1. 包含多个不可用数据源（sina, efinance, tickflow）
2. 包含实时行情数据源（tencent）
3. 没有针对日频策略优化

### 新降级链（针对日频策略优化）

#### 方案A：保守方案（仅使用已验证可用的数据源）
```json
"fallback_chain": [
    "akshare",     // 第一优先级：历史K线已验证可用
    "baostock"    // 第二优先级：如果网络恢复，历史数据可靠
]
```

**优点**：
- 稳定可靠
- 仅包含已验证或理论可用的数据源

**缺点**：
- 缺少备用数据源
- 如果AKShare失败，没有即时备用

#### 方案B：积极方案（包含需要配置的数据源）
```json
"fallback_chain": [
    "akshare",     // 第一优先级：历史K线已验证可用
    "itick",       // 第二优先级：如果配置了token，日频数据稳定
    "baostock",   // 第三优先级：如果网络恢复，历史数据可靠
    "tencent"     // 第四优先级：仅指数数据，作为补充
]
```

**优点**：
- 有多个备用数据源
- 充分利用所有可能的日频数据源

**缺点**：
- itick需要配置token
- baostock需要网络恢复

#### 推荐：方案A（保守方案）
**原因**：
1. 您做的是日频策略，稳定性最重要
2. AKShare历史K线已验证可用
3. 先保证系统稳定工作，再逐步添加备用数据源

#### 1. 修改 `primary_source`

#### 2. 修改 `fallback_chain`
```json
"fallback_chain": [
    "akshare",     // 第一优先级：历史K线已验证可用
    "baostock",   // 第二优先级：历史数据可靠（如果网络恢复）
```

**移除的数据源**：
- `sina`：HTTP 403，需要爬虫
- `efinance`：连接失败
- `tickflow`：需要API密钥

**新增的数据源**：
- 无（暂时不添加 itick，需要配置token）

#### 3. 修改 `cache_hours`
```json
"cache_hours": 24  // 从4小时改为24小时（日频策略，不需要频繁刷新）
```

**原因**：
- 日频策略，数据每天更新一次
- 延长缓存时间，减少对外网数据源的请求
- 提高系统稳定性

#### 4. 修改 `ttl` 配置
```json
"ttl": {
    "kline_daily": 86400,           // 日K线：缓存1天
    "index_quote": 86400,           // 指数数据：缓存1天
    "company_fundamentals": 604800,  // 基本面数据：缓存7天
    "industry_info": 604800          // 行业信息：缓存7天
}
```

**移除的TTL配置**（实时行情相关）：
- `realtime_quote`: 300  // 不需要实时行情
- `north_flow`: 300        // 不需要北向资金实时数据
- `market_breadth`: 300     // 不需要市场广度实时数据
- `hot_stocks`: 300         // 不需要热门股票实时数据

**原因**：
- 您做的是日频策略，不需要实时行情
- 移除这些配置，减少系统复杂度和不必要的API调用

```python
# providers/itick_data.py
class ItickDataSource:
    def __init__(self, token):
        self.base_url = "https://api.itick.org"
        self.token = token
        self.headers = {
            "accept": "application/json",
            "token": self.token
        }
    
    def get_daily_kline(self, code, market="SH", limit=100):
        """获取日K线数据"""
        url = f"{self.base_url}/stock/kline"
        params = {
            "region": market,
            "code": code,
            "kType": 10,  # 10=日K线
            "limit": limit
        }
        
        response = requests.get(url, headers=self.headers, params=params, timeout=10)
        if response.status_code == 200:
            data = response.json()
            if data.get("code") == 200:
                return data.get("data", [])
        return None
```

然后在 `providers/market_data.py` 中添加：

```python
def _source_itick(self, method_name, *args):
    """从 itick.org 获取数据"""
    if not hasattr(self, 'itick'):
        token = self.config.get('itick_token')
        if not token:
            return None
        self.itick = ItickDataSource(token)
    
    # 调用对应的方法
    method = getattr(self.itick, method_name, None)
    if method:
        return method(*args)
    return None
```
