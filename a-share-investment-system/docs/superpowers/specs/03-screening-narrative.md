## SSE事件驱动

前端建立 EventSource 连接后，根据事件名推进叙事流：

```
market_diagnosis  → 显示市场诊断卡片
agent_proposal    → 追加Agent动议卡片（可多次）
debate_round      → 显示辩论面板（可多次）
final_recommendation → 显示最终推荐表格
```

## 状态管理

```typescript
interface ScreeningState {
  marketState: MarketDiagnosis | null
  agentProposals: AgentProposal[]
  debateRounds: DebateRound[]
  recommendations: Recommendation[]
  status: 'idle' | 'diagnosing' | 'proposing' | 'debating' | 'complete'
}
```
