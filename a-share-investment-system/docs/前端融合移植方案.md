# AShare-X 功能融合移植方案

> 将 TradingAgents-CN 和 TradingAgents-AShare 的功能与页面布局移植到 a-share-investment-system

---

## 一、现状分析

### 1.1 各项目前端对比

| 项目 | 框架 | UI库 | 页面数 | 可以移植的资源 |
|------|------|------|--------|---------------|
| **a-share-X (现有)** | Vue 3 | Element Plus | 5页 | 接收方，基础布局已就绪 |
| **TradingAgents-CN** | Vue 3 | Element Plus | 15+页 | **同栈直接复用** |
| **TradingAgents-AShare** | React 18 | TailwindCSS | 7页 | 需React→Vue重写 |

### 1.2 现有 a-share-X 前端结构

```
frontend/src/
├── App.vue                  ← 根组件
├── main.ts                  ← 入口
├── api/request.ts           ← API层
├── layouts/BasicLayout.vue  ← 侧边栏布局 (5项导航)

├── views/

│   ├── Portfolio/           ← 持仓: 盈亏表格
│   ├── Screening/           ← 选股: 3阶段筛选
│   ├── Database/            ← 数据库: 多表管理
│   └── Logs/                ← 日志: 实时流

```

## 四、关键组件移植细节

### 4.1 AgentGraph.vue（Agent协作图）

> **来源**: TradingAgents-AShare `AgentCollaboration.tsx`（React Flow → Vue 3 重写）

**技术选型**: `@vue-flow/core`（Vue 3 版本的 React Flow）

**核心功能**:
- 渲染14个Agent节点，4列布局（分析师→研究员→交易员→风控→组合经理）
- 实时状态更新（pending/in_progress/completed/skipped）
- 节点点击跳转到对应报告区域或打开辩论面板
- 分组标签（虚线边框）："技术分析"、"研究团队"、"风控团队"
- 完成节点显示判决摘要

### 4.2 KlineChart.vue（K线图）

> **来源**: TradingAgents-AShare `KlinePanel.tsx`（lightweight-charts → ECharts重写）

**技术选型**: ECharts（与CN项目保持一致）

**核心功能**:
- 蜡烛图 + 成交量
- 默认180天范围
- 十字光标 + OHLCV tooltip
- 指数预设按钮（上证、深证、创业板、科创50、北证50）
- 暗色/亮色主题自适应

### 4.3 DebatePanel.vue（辩论面板）

> **来源**: TradingAgents-AShare `DebateDrawer.tsx`（React → Vue 3 重写）

**技术选型**: Element Plus Drawer + Timeline

**核心功能**:
- 右侧滑入面板（w-1/2，max 720px）
- 两种模式："多空辩论"和"风控三方辩论"
- 按Round分组的时间线
- Token级别流式显示每段发言
- 底部判决卡片
- 自动滚动（用户上滚时暂停）

### 4.4 ChatCopilot.vue（聊天助手）

> **来源**: TradingAgents-AShare `ChatCopilotPanel.tsx`（React → Vue 3 重写）

**技术选型**: Element Plus + 自定义SSE

**核心功能**:
- 自然语言输入框
- SSE流式响应
- Agent消息气泡 + 打字机效果
- 预设提示按钮
- 状态指示器（typing/parsing/collecting/analyzing）
- 报告完成时显示卡片
- 中断任务自动恢复

### 4.5 DecisionCard.vue（决策卡片）

> **来源**: TradingAgents-AShare `DecisionCard.tsx`

**技术选型**: Element Plus Card + Progress

**核心功能**:
- 方向徽章（买入/卖出/持有）
- 置信度进度条
- 目标价、止损价
- 可展开的推理详情

### 4.6 ReportViewer.vue（报告查看器）

> **来源**: TradingAgents-AShare `ReportViewer.tsx`

**技术选型**: Element Plus Collapse + 自定义Markdown渲染

**核心功能**:
- 可折叠分段（10种报告类型）
- 流式打字机效果
- Markdown渲染
- 导出下载按钮
- 同股票历史时间线

## 七、风险与注意事项

| 风险 | 缓解措施 |
|------|---------|
| CN页面依赖MongoDB/Redis | API路径统一为 `/api/` 前缀 |
| CN页面有JWT认证 | 在前端层面移除认证检查 |
| React→Vue组件行为差异 | 使用Vue流式方案替代React hooks |
| 后端API缺失 | 先建立mock，后逐步实现后端 |
| 包体积增大 | echarts按需引入，code splitting |
