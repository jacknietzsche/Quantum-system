# 4. 工作流引擎

## 4.1 Daily Analysis Workflow (LangGraph)

```
                    ┌─────────────┐
                    │  START      │
                    │  (用户触发)  │
                    └──────┬──────┘
                           ↓
                    ┌─────────────┐
                    │ 1. Data Check│
                    │  (检查数据    │
                    │   新鲜度)    │
                    └──────┬──────┘
                           ↓
              ┌────────────┴────────────┐
              │ data outdated           │ data ok
              ↓                         ↓
    ┌─────────────┐            ┌─────────────┐
    │ 1a. Refresh │            │ 2. Market    │
    │  Data       │            │  Analysis    │
    │  (自动拉取)  │            │  (MarketAgent)│
    └──────┬──────┘            └──────┬──────┘
           │                         │
           └────────────┬────────────┘
                        ↓
                 ┌─────────────┐
                 │ 3. Screening│
                 │  (4阶段漏斗) │
                 └──────┬──────┘
                        ↓
          ┌─────────────┴─────────────┐
          │ candidates > 20           │ candidates ≤ 20
          ↓                           ↓
  ┌─────────────┐            ┌─────────────┐
  │ 4. Batch     │            │ 直接进入     │
  │  Deep Dive   │            │ 排序汇总     │
  │  (并发Analyst│            │             │
  │   Agent×N)   │            │             │
  └──────┬──────┘            └──────┬──────┘
         │                         │
         └────────────┬────────────┘
                      ↓
               ┌─────────────┐
               │ 5. Risk      │
               │  Analysis    │
               │  (Portfolio   │
               │   Agent)     │
               └──────┬──────┘
                      ↓
               ┌─────────────┐
               │ 6. Generate  │
               │  Report      │
               │  (HTML+PDF)  │
               └──────┬──────┘
                      ↓
               ┌─────────────┐
               │ 7. Wait User│
               │  (确认是否   │
               │   发送邮件)  │
               └──────┬──────┘
                      ↓
               ┌─────────────┐
               │  END        │
               └─────────────┘
```

## 4.2 Stock Deep Dive Workflow

```
┌─────────────┐
│  START      │
│  (用户输入   │
│   股票代码)  │
└──────┬──────┘
       ↓
┌─────────────┐
│ 1. Fetch Data│
│  K线+基本面  │
└──────┬──────┘
       ↓
┌─────────────┐         ┌─────────────┐
│ 2a. Factor  │         │ 2b. Master  │
│  Scoring    │         │  Scoring    │
└──────┬──────┘         └──────┬──────┘
       │                       │
       └────────────┬──────────┘
                    ↓
             ┌─────────────┐
             │ 3. Debate   │
             │  (牛熊辩论)  │
             └──────┬──────┘
                    ↓
             ┌─────────────┐
             │ 4. Risk     │
             │  Assessment │
             └──────┬──────┘
                    ↓
             ┌─────────────┐
             │ 5. Generate │
             │  Response   │
             └──────┬──────┘
                    ↓
             ┌─────────────┐
             │  END        │
             └─────────────┘
```

## 4.3 Report & Email Workflow

```
┌─────────────┐
│  START      │
│  (用户:发送  │
│   报告)      │
└──────┬──────┘
       ↓
┌─────────────┐
│ 1. Generate │
│  HTML Report│
└──────┬──────┘
       ↓
┌─────────────┐
│ 2. Generate │
│  PDF Report │
│  (optional) │
└──────┬──────┘
       ↓
┌─────────────┐
│ 3. Preview  │
│  (前端展示)  │
└──────┬──────┘
       ↓
┌─────────────┐
│ 4. Send     │
│  Email      │
│  (QQ SMTP)  │
└──────┬──────┘
       ↓
┌─────────────┐
│ 5. Confirm  │
│  (发送结果)  │
└──────┬──────┘
       ↓
┌─────────────┐
│  END        │
└─────────────┘
```
