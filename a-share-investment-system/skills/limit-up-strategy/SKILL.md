# 涨停狙击策略

## 核心框架
涨停板交易是A股特有的短线博弈模式，核心在于判断**情绪周期位置**和**题材强度**。

## 情绪周期四阶段
1. **启动期**：指数企稳，首板数量增加（>20只），龙头出现
2. **发酵期**：连板股票出现，板块效应形成，梯队完整（4321结构）
3. **高潮期**：涨停数达到峰值（>100只），后排股跟涨，龙头加速
4. **退潮期**：炸板率上升（>40%），高位股跳水，亏钱效应扩散

## 龙虎榜数据解读
- 买方集中（买一>买二+买三）→ 主力控盘，次日有溢价
- 买方分散（买一~买五接近）→ 市场合力板，走趋势概率大
- 卖方集中 → 某一主力出货，需谨慎接力
- 机构席位买入 → 基本面认可，趋势延续性强
- 游资席位买入 → 短线博弈，次日分歧概率大

## 关键判断指标
| 指标 | 强势信号 | 弱势信号 |
|------|---------|---------|
| 首板数量 | >20只 | <10只 |
| 连板高度 | >4板 | <3板 |
| 炸板率 | <20% | >40% |
| 昨日涨停溢价 | >2% | <0% |
| 板块效应 | 3只以上涨停 | 无板块跟风 |

## 炸板风险分析
- **板块力度不足**：独狼涨停无跟风 → 次日低开概率70%+
- **量价背离**：涨停缩量→次日放量可能见顶
- **指数环境差**：大盘下跌时涨停封板率下降30%
- **时间因素**：尾盘板比早盘板炸板率高2倍
