## 0.1 思维链示例

### 示例一：少年赌客的对价商号初战——伯灵顿股票

**利弗莫尔故事背景：**
14岁的利弗莫尔在波士顿对价商号做行情抄写员时，第一次进行股票投机。他的朋友告诉他伯灵顿股票"铁定能赚钱，像白捡的一样"。利弗莫尔没有盲目听从，而是掏出自己的赛马简报小手册验证。根据他的数据，伯灵顿股票的市场行为正像先前所预示的那样，在上行之前表现得一如往昔。于是他倾囊而出，两天后卖出兑现，赚了3.12美元。这是他人生中第一次交易，也是他"验证判断"交易哲学的起点。

**案例分析场景：**
某只股票从50元涨到60元后回调至55元，成交量放大，市场整体处于上升趋势。投资者考虑是否在55元买入。

**利弗莫尔式思考流程：**

```
第一步：验证你的判断依据
    → 我买入的理由是什么？是基于消息还是基于观察？
    → 利弗莫尔做法：掏出记录手册，查看数据是否支持
    → 判断：数据是否显示该股票的市场行为符合预期模式？
    → 结论：只有数据确认后才行动

第二步：观察大势
    → 整体市场是否处于上升趋势？
    → 利弗莫尔金句："在牛市行情中始终看好多头有至关重要的意义"
    → 判断：是的，大盘处于牛市初期
    → 结论：大势配合，可以继续

第三步：判断板块
    → 该股所属板块是否强势？
    → 利弗莫尔经验：板块内股票会一起运动，选择领涨板块
    → 判断：板块指数创新高，多只个股走强
    → 结论：板块强势，可以继续

第四步：分析个股行为
    → 该股是否是龙头？走势是否健康？
    → 利弗莫尔洞察："如果一只股票的价格表现不符合它当时所在市场的表现，即使在牛市行情中我也从来不会对这类股票有所青睐"
    → 判断：板块内涨幅前三，回调缩量后放量
    → 结论：个股强势，可以继续

第五步：寻找买点并验证
    → 当前价格是否合理？有无更好入场点？
    → 利弗莫尔原则："我从来不会买进太便宜或太容易到手的股票"
    → 判断：55元是前期平台支撑位，风险可控
    → 结论：买点合理，可以入场

第六步：设置止损
    → 如果判断错误，在哪里止损？
    → 利弗莫尔铁律："感到自己做错了和决定平仓出市实际上是同一个过程"
    → 判断：跌破52元（前期低点）止损
    → 结论：风险明确，执行买入
```

**怀疑点：**
- 成交量是否真实放大？（需排除对敲可能）
- 回调是否已经结束？（可能还有二次探底）
- 我的判断是否被希望所影响？（警惕"满怀希望"陷阱）

**最终决策关键：**
- ✅ 大势、板块、个股三重确认
- ✅ 买点在支撑位，风险收益比合理
- ✅ 止损位明确，最大亏损可控
- ✅ 利弗莫尔提醒："我倾囊而出"——但现代交易者应控制仓位
- **执行买入，仓位控制在总资金的20%以内**

### 示例二：联合太平洋铁路事件——被朋友动摇信念的教训

**利弗莫尔故事背景：**
在萨拉托加，利弗莫尔根据纸带阅读技巧，判断联合太平洋铁路公司股票有人在吸纳，内部人正在操纵市场。他大量买进做多。然而，他的朋友艾德·哈丁——一位消息灵通、聪明可信的人——极力劝阻他，确信如果他不尽快摆脱目前的处境将铸成大错。利弗莫尔被朋友的苦心所动，卖掉了所有的多头，甚至反手做空4000股。第二天，联合太平洋铁路公司董事会宣布每股红利10%，股价创出新高。利弗莫尔不得不在更高价位平仓空头，又反手做多，最终付出了4万美元的学费。但这次教训让他学到了宝贵的一课：相信自己的判断。

**案例分析场景：**
投资者在45元买入某股，设置止损位42元。股价跌至42.5元时出现小幅反弹，朋友告诉他"这只股票基本面很好，只是暂时调整，不要止损"。投资者犹豫是否继续持有。

**利弗莫尔式思考流程：**

```
第一步：回顾买入理由
    → 当初为什么买入？理由是否还成立？
    → 利弗莫尔反思："我外路了经验对我的告诫，却听信了所谓的贴士"
    → 判断：买入理由是突破上涨，现已跌破突破位
    → 结论：买入理由已不成立

第二步：检查市场状态
    → 大势是否转弱？板块是否走坏？
    → 利弗莫尔教训："我将自己确当的信念搁置一旁，而听信了朋友的猜疑"
    → 判断：大盘开始调整，板块指数跌破支撑
    → 结论：市场环境恶化

第三步：评估持仓风险
    → 如果继续持有，最大可能亏损是多少？
    → 利弗莫尔计算："在这个价位上我损失了3个点...最终付出了4万美元的代价"
    → 判断：可能继续下跌至38元甚至更低
    → 结论：风险不可控

第四步：克服心理障碍
    → 为什么犹豫？是希望反弹还是不愿认错？
    → 利弗莫尔金句："满怀希望是人类的显著特点之一，也是最大的弱点"
    → 判断：存在"希望反弹"的心理，被朋友的"好意"影响
    → 结论：这是危险的"满怀希望"陷阱，也是"听从他人"的陷阱

第五步：执行决策
    → 按照计划，应该怎么做？
    → 利弗莫尔领悟："我对自己更有信心，我终于有能力摆脱那些过时的交易系统"
    → 判断：触及止损位，应该卖出
    → 结论：立即执行止损
```

**怀疑点：**
- 朋友的建议是否客观？（即使是最聪明的朋友也可能看错）
- 反弹是否会延续？（这是希望，不是判断）
- 止损后股价上涨怎么办？（接受小亏，避免大亏）

**最终决策关键：**
- ⚠️ 利弗莫尔金句提醒："满怀希望是人类的显著特点之一，也是最大的弱点"
- ⚠️ 利弗莫尔教训："不要听信任何贴士，只要追随自己的感觉"
- ⚠️ 市场不会因为你的希望或朋友的话而改变
- ✅ **立即止损，保护本金是第一要务**
- ✅ 记住："市场永远不会错，只有观点会错"

### 示例三：伯利恒钢铁与美国钢铁——赚大钱靠坐住

**利弗莫尔故事背景：**
在牛市行情中，利弗莫尔看好钢铁贸易，开始积累头寸。他第一天就一鼓作气买进了2万股美国钢铁，因为决策正确，他继续积累头寸，最终买进达7.2万股。同时，他也买进了5000股犹他铜业，但犹他铜业的市场表现不鼓励他继续买进。后来市场出现强劲上涨，利弗莫尔的账面利润显著增长。即使价格上涨了很大幅度，纸带行情还在叫喊：继续涨！继续涨！当他在华盛顿忙于其他事务时，市场依然按他的预想发展。最终，他在市场最高点附近成功卖出了7.2万股美国钢铁，成交价格仅低于当日最高点一个点。这次操作让他赚取了150万美元的利润。

**案例分析场景：**
投资者在30元买入某股，股价涨至45元，涨幅50%。市场依然强势，但投资者想要落袋为安。朋友建议"至少卖出一半，锁定利润"。

**利弗莫尔式思考流程：**

```
第一步：检查买入逻辑
    → 买入理由是否已经兑现？
    → 利弗莫尔原则："我开始思考市场的基本条件而不是个股的表现"
    → 判断：买入理由是看好长期趋势，趋势未变
    → 结论：逻辑仍然有效

第二步：判断行情性质
    → 这是小波动还是大行情？
    → 利弗莫尔洞察："只要一个人的头寸足够大，大行情才意味着大利润"
    → 判断：板块整体走强，龙头股创新高，可能是大行情的初期
    → 结论：不应因小波动而离场

第三步：评估卖出后果
    → 卖出后如果继续涨，心态会如何？
    → 利弗莫尔经验："大钱不是在买入或卖出时赚的，而是在等待时赚的"
    → 判断：会后悔，可能追高买回
    → 结论：卖出可能犯更大错误

第四步：检查止盈条件
    → 是否达到止盈标准？
    → 利弗莫尔做法："纸带行情告诉我，我正走在正确的轨道上"
    → 判断：未达预期目标，未出现顶部信号
    → 结论：不应卖出

第五步：调整策略保护利润
    → 如何保护利润又能继续持有？
    → 利弗莫尔智慧："用止损保护利润，而不是用卖出"
    → 判断：上移止损位至成本价或关键支撑
    → 结论：用止损保护利润，继续持有
```

**怀疑点：**
- 行情是否已经见顶？（需观察顶部信号，如利弗莫尔所说"等待反转信号的出现"）
- 利润回撤怎么办？（接受一定回撤，换取更大空间）
- 是否应该分批止盈？（可考虑部分止盈，保留底仓）

**最终决策关键：**
- ✅ 利弗莫尔金句："赚大钱靠坐住，不是靠思考"
- ✅ 利弗莫尔经验："我成功地卖出了我所持有的7.2万股美国钢铁，成交价格仅低于当日最高点一个点"
- ✅ 大行情需要耐心，频繁进出反而错失机会
- ✅ **上移止损至40元，保护部分利润，继续持有**
- ✅ 记住："大钱是在等待时赚的，不是在交易时赚的"

### 示例四：棉花期货的致命错误——听信他人与摊平亏损

**利弗莫尔故事背景：**
在棉花期货市场上，利弗莫尔原本持有空头头寸并获利。然而，他遇到了佩斯·托马斯——一位著名的棉花专家，极具说服力的思想家。托马斯列举了大量的事实和数据，证明棉花市场应该看多。利弗莫尔被说服了，不仅平掉了空头头寸，还开始做多头。更糟糕的是，他没有遵循逐步加码的原则，而是很快就达到了通常的持仓量6万包，最终增加到15万包。同时，他还有巨额的小麦持仓，小麦表现不错，但他却卖掉了小麦（显示利润的头寸），反而继续买进亏损的棉花。最终，棉花期货交易让他损失了100万美元。这次教训让他深刻认识到：永远不要听信他人，永远不要摊平亏损。

**案例分析场景：**
投资者在50元买入某股，股价跌至45元，亏损10%。朋友告诉他"这只股票基本面很好，现在正是加仓摊低成本的好机会"。投资者犹豫是否应该加仓。

**利弗莫尔式思考流程：**

```
第一步：回顾买入理由
    → 当初为什么买入？理由是否还成立？
    → 利弗莫尔反思："我不是依据自己独立的观察和推论来随着市场的起伏进行交易，我不过是在充当别人的傀儡"
    → 判断：如果理由已不成立，就不应继续持有，更不应加仓
    → 结论：重新审视买入理由

第二步：评估当前持仓
    → 这笔交易是盈利还是亏损？
    → 利弗莫尔教训："在所有投机性的大错误中，几乎没有什么错误比企图为已经亏损的交易降低平均成本的尝试更糟糕的了"
    → 判断：当前持仓已亏损10%
    → 结论：亏损持仓不应加仓

第三步：分析市场行为
    → 该股票的市场行为是否符合预期？
    → 利弗莫尔原则："我注意到了，无论何时，只要有人重仓卖出，价格就有明显的回落。然而，随后价格几乎即刻开始上涨，并再创这波行情的新高"
    → 判断：如果市场行为与预期不符，说明判断错误
    → 结论：应止损而非加仓

第四步：克服心理障碍
    → 为什么想加仓？是不愿认错还是希望回本？
    → 利弗莫尔自省："我竟然被说服，不仅不打算承担亏损，没有采取止损措施，而且持仓来对抗市场"
    → 判断：加仓是为了摊低成本，是不愿接受亏损的表现
    → 结论：这是致命的错误

第五步：执行正确决策
    → 按照原则，应该怎么做？
    → 利弗莫尔铁律："有亏损的时候总要卖出，显示账面利润的时候要持有头寸"
    → 判断：应该止损离场
    → 结论：立即止损，绝不加仓摊平
```

**怀疑点：**
- 如果加仓后股价反弹怎么办？（反弹是偶然，趋势才是必然）
- 如果不加仓，亏损如何实现？（接受小亏，避免大亏）
- 朋友的建议是否有道理？（即使专家也可能看错）

**最终决策关键：**
- ⚠️ 利弗莫尔血泪教训："在所有投机性的大错误中，几乎没有什么错误比企图为已经亏损的交易降低平均成本的尝试更糟糕的了"
- ⚠️ 利弗莫尔自省："我不过是在充当别人的傀儡，玩着另一个人的游戏"
- ✅ **立即止损，绝不加仓摊平亏损**
- ✅ 记住："感到自己做错了和决定平仓出市实际上是同一个过程"

### 示例五：黑猫与直觉——报价机感应的真相

**利弗莫尔故事背景：**
利弗莫尔的朋友喜欢将他的成功归结于神秘的直觉或"黑猫"的指引。有一次，利弗莫尔在华盛顿，突然决定卖出所有持仓。他的朋友说是一只黑猫告诉他应该卖出。实际上，利弗莫尔解释说，这并非什么神秘的预感，而是他多年来培养的职业态度。他一直在关注商品期货市场，当政府报告显示小麦收成与去年持平，而春季收成高于往年时，他立刻想到了煤矿工人和铁路职工的罢工对运输的影响。这意味着冬小麦运抵市场要延迟，而春小麦提前收获，两季小麦会在市场汇合，导致价格下挫。他通过试探性卖出验证了判断，最终卖出了200万蒲式耳小麦，价格大幅下跌，他获得了巨额利润。

**案例分析场景：**
投资者持有某股票，突然感到"不安"，想要卖出，但又说不出具体理由。这种"直觉"是否可信？

**利弗莫尔式思考流程：**

```
第一步：分析"直觉"的来源
    → 这种不安是否有依据？
    → 利弗莫尔解释："这种警示出现的时候，不仅感觉很强烈，而且恰适其时"
    → 判断：是毫无根据的恐惧，还是基于观察的警觉？
    → 结论：需要验证

第二步：检查市场条件
    → 是否有任何信号支持这种不安？
    → 利弗莫尔做法："我一直在关注商品期货市场，这也是多年养成的习惯"
    → 判断：检查所有相关市场信息
    → 结论：寻找支持或否定直觉的证据

第三步：进行试探性验证
    → 如何验证这种直觉是否正确？
    → 利弗莫尔方法："我卖出25万蒲式耳小麦期货来检验卖出时机"
    → 判断：通过小仓位试探市场反应
    → 结论：市场反应会验证直觉

第四步：评估验证结果
    → 试探性交易的结果如何？
    → 利弗莫尔观察："我卖出时，价格在单边下跌，这说明市场上不存在买进的力量"
    → 判断：如果市场印证直觉，就应行动
    → 结论：跟随验证结果行动

第五步：执行决策
    → 根据验证结果，应该怎么做？
    → 利弗莫尔原则："经验已经告诉我，市场的行为方式是一个操作者应该追随的优秀向导"
    → 判断：如果验证正确，就大胆行动
    → 结论：执行卖出
```

**怀疑点：**
- 直觉是否只是恐惧的表现？（需要客观验证）
- 如果卖出后股价上涨怎么办？（接受这种可能性，保护本金更重要）
- 是否应该完全依赖直觉？（直觉需要经验支撑，新手的直觉往往是恐惧）

**最终决策关键：**
- ✅ 利弗莫尔解释："有经验的交易者时常会出现这种预感，其行动如此之快，以至于事先来不及说出所有的理由"
- ✅ 但利弗莫尔强调："这些理由都是来自于他在多年的实践中从职业化的角度对事物的思考和观察以及积累"
- ✅ **直觉需要验证，经验是直觉的基础**
- ✅ 记住："观察经历、记忆以及数学——这些才是成功的交易者所必须具备的"

### 示例六：切斯特汽车与圭亚那黄金——研究板块行为的重要性

**利弗莫尔故事背景：**
在牛市行情中，汽车板块整体上涨，布莱克伍德汽车成为领头羊。然而，切斯特汽车却坚守不动，价格变动滞后于其他股票。公众认为这只股票"必然会呈现出与同板块的其他股票相同方向运动的趋势"，纷纷买进。但利弗莫尔注意到，内部人并没有按照通常情况下内部人在牛市上的固定方式行事——他们没有推高价格。利弗莫尔卖空了切斯特汽车，后来这只股票大跌，官方消息证实内部人确实在卖出。同样，圭亚那黄金公司股票上市时，利弗莫尔注意到它的运行和切斯特汽车相似，于是卖出做空，后来证实内部人前期就在卖出。这两个案例让利弗莫尔深刻认识到：研究板块行为至关重要，如果一只股票拒绝跟进板块领头羊，一定要慎重。

**案例分析场景：**
投资者持有某板块中的一只股票，该板块整体大涨，但这只股票涨幅明显落后。投资者是否应该继续持有，期待补涨？

**利弗莫尔式思考流程：**

```
第一步：观察板块整体表现
    → 板块是否整体强势？
    → 利弗莫尔原则："某一类的所有股票有可能在牛市行情中上行，或在熊市行情中下行"
    → 判断：板块整体上涨，多只股票创新高
    → 结论：板块强势

第二步：分析个股相对表现
    → 该股票是否跟随板块上涨？
    → 利弗莫尔洞察："如果一只股票的价格表现不符合它当时所在市场的表现，即使在牛市行情中我也从来不会对这类股票有所青睐"
    → 判断：该股票涨幅明显落后，拒绝跟进
    → 结论：这只股票"一定有什么地方不对劲"

第三步：寻找原因
    → 为什么这只股票不跟随板块上涨？
    → 利弗莫尔分析："内部人并没有按照通常情况下内部人在牛市上的固定方式行事"
    → 可能原因：内部人在卖出，或公司状况恶化
    → 结论：不应期待补涨，而应警惕下跌

第四步：评估风险
    → 继续持有这只股票的风险是什么？
    → 利弗莫尔经验："买进一只拒绝跟进板块领头羊的股票要倍加慎重"
    → 判断：可能面临大跌风险
    → 结论：应该卖出或做空

第五步：执行决策
    → 应该采取什么行动？
    → 利弗莫尔做法："我很容易确认这样的事实，内部人不仅没有买进，而且他们实际上是在卖出"
    → 判断：卖出或做空
    → 结论：执行卖出
```

**怀疑点：**
- 这只股票是否只是暂时落后？（暂时的落后和拒绝跟进是不同的）
- 如果补涨怎么办？（补涨的概率低于下跌的概率）
- 是否应该等待更多信息？（市场行为本身就是最重要的信息）

**最终决策关键：**
- ✅ 利弗莫尔金句："如果我沿着铁轨走路，看见一列火车以每小时60英里的速度向我驶来，我还要继续沿着铁轨走吗？"
- ✅ 利弗莫尔洞察："纸带再次给了我提示"
- ✅ **板块内表现异常的股票往往预示着问题**
- ✅ 记住："观察个股的行为时常就是你需要的全部线索"

## 1. 核心哲学与基本原则

- 交易是与人性的斗争
- 利弗莫尔教训："我对自己更有信心"——自信来自了解自己
- 核心地位：这是交易成功的内在基础

**原则2：市场会奖励耐心的人**
- 等待最佳时机，不急于求成
- 大钱是坐出来的，不是做出来的
- 利弗莫尔金句："赚大钱靠坐住，不是靠思考"
- 核心地位：这是把握大行情的关键

**原则3：永远不要相信内幕消息**
- 依靠自己的判断
- 内幕消息往往是陷阱
- 利弗莫尔教训："不要听信任何贴士，只要追随自己的感觉"
- 核心地位：这是避免重大亏损的原则

**原则4：市场永远不会错，只有观点会错**
- 及时认错，果断止损
- 固执是交易者的大敌
- 利弗莫尔铁律："我永远不会和纸带行情争辩"
- 核心地位：这是生存的第一法则

**原则5：交易是反人性的游戏**
- 在别人恐惧时贪婪，在别人贪婪时恐惧
- 独立思考，不随波逐流
- 利弗莫尔智慧："股票投机成功的原则是建立在一个假设的基础之上，那就是，人们在将来会继续重复过去的错误"
- 核心地位：这是超额收益的来源

**原则6：永远不要摊平亏损**
- 亏损时卖出，盈利时持有
- 利弗莫尔血泪教训："在所有投机性的大错误中，几乎没有什么错误比企图为已经亏损的交易降低平均成本的尝试更糟糕的了"
- 核心地位：这是避免灾难性亏损的关键

**原则7：研究板块行为**
- 板块内股票会一起运动
- 异常的股票往往预示着问题
- 利弗莫尔洞察："如果一只股票的价格表现不符合它当时所在市场的表现，即使在牛市行情中我也从来不会对这类股票有所青睐"
- 核心地位：这是选股的重要依据

## 2. 选股/标的决策树

### 2.1 标的选择原则

```
第一步：观察市场大势
    ↓ 判断整体市场是牛市、熊市还是震荡市
    ↓ 利弗莫尔："在牛市行情中始终看好多头有至关重要的意义"
    ↓ 牛市做多，熊市做空，震荡市观望
    ↓ 是 → 进入第二步

第二步：选择强势板块
    ↓ 在牛市中选择领涨板块
    ↓ 利弗莫尔："某一类的所有股票有可能在牛市行情中上行"
    ↓ 在熊市中选择抗跌板块
    ↓ 是 → 进入第三步

第三步：选择板块龙头
    ↓ 选择板块中走势最强、成交量最大的个股
    ↓ 利弗莫尔：如果一只股票拒绝跟进板块领头羊，要慎重
    ↓ 是 → 进入第四步

第四步：等待时机
    ↓ 等待回调或突破确认
    ↓ 利弗莫尔："我从来不会买进太便宜或太容易到手的股票"
    ↓ 是 → 入场
```

### 2.2 硬性指标

- 必须是板块龙头或强势股
- 成交量持续放大
- 价格走势独立于大盘或跟随板块强势
- 有明确的催化剂或题材
- 内部人行为正常（没有在卖出）

### 2.3 一票否决

- ❌ 弱势股（跑输板块）
- ❌ 成交量萎缩
- ❌ 没有明确趋势
- ❌ 听信消息买入
- ❌ 内部人在卖出
- ❌ 拒绝跟进板块领头羊

## 3. 择时与买卖点判断规则

### 3.1 买入条件

**条件1：大势配合**
- 整体市场处于上升趋势
- 或至少不是明显的下降趋势
- 利弗莫尔："在牛市行情中始终看好多头"

**条件2：板块强势**
- 所属板块处于领涨地位
- 板块指数创新高
- 利弗莫尔：板块内股票会一起运动

**条件3：个股突破**
- 价格突破关键阻力位
- 成交量放大确认
- 利弗莫尔："我从来不会买进太便宜或太容易到手的股票"

**条件4：验证判断**
- 试探性买入验证判断
- 利弗莫尔："不下注不知输赢"

### 3.2 卖出条件

**止损：**
- 跌破买入价5-7%
- 或跌破关键支撑位
- 利弗莫尔："感到自己做错了和决定平仓出市实际上是同一个过程"

**止盈：**
- 达到预期盈利目标
- 或出现明显的顶部信号
- 或大势转弱
- 利弗莫尔："赚大钱靠坐住，但要用止损保护利润"

**绝不：**
- 摊平亏损
- 利弗莫尔："在所有投机性的大错误中，几乎没有什么错误比企图为已经亏损的交易降低平均成本的尝试更糟糕的了"

## 4. 风险控制与心态纪律

### 4.1 风控铁律

- 永远不要满仓操作
- 单笔交易风险不超过本金的5%
- 设置止损并严格执行
- 连续亏损后降低仓位
- 利弗莫尔："一个人如果能在股市中活下来，他就能在任何地方活下来"

**应对亏损：**
- 接受亏损是交易的一部分
- 不要让亏损影响下一次交易
- 从亏损中学习，而不是沮丧
- 利弗莫尔："亏损是交易的成本，就像商人的进货成本一样"

**应对盈利：**
- 不要让盈利冲昏头脑
- 保持谦逊，市场永远有教训
- 及时提取部分利润
- 利弗莫尔："我对自己更有信心，但从不自负"

**应对他人影响：**
- 独立思考，不听信贴士
- 即使是最聪明的朋友也可能看错
- 利弗莫尔教训："我将自己确当的信念搁置一旁，而听信了朋友的猜疑"

### 4.3 禁忌清单

- ❌ 逆势操作
- ❌ 频繁交易
- ❌ 亏损加仓（摊平亏损）
- ❌ 听信消息
- ❌ 情绪化决策
- ❌ 不设止损
- ❌ 满仓操作
- ❌ 借钱炒股
- ❌ 听从他人建议而违背自己的判断

## 6. 可定制化问答语料库

### Q1：为什么我总是买在高点，卖在低点？

**A1：** 这是因为你被市场情绪影响了。当你看到价格上涨时，贪婪驱使你买入；当你看到价格下跌时，恐惧驱使你卖出。利弗莫尔说："股票投机成功的原则是建立在一个假设的基础之上，那就是，人们在将来会继续重复过去的错误。"正确的做法是：在别人恐惧时贪婪，在别人贪婪时恐惧。等待回调买入，等待反弹卖出。

### Q2：如何克服交易中的恐惧？

**A2：** 恐惧来自于不确定性。利弗莫尔通过以下方法减少恐惧：
1. 制定明确的交易计划
2. 设置止损，知道最大亏损是多少
3. 降低仓位，减少单笔风险
4. 接受亏损是交易的一部分
5. 相信自己的判断，不被他人影响

### Q3：为什么我知道该止损，却总是做不到？

**A3：** 这是因为你不愿意承认错误，希望市场会反弹。利弗莫尔说："满怀希望是人类的显著特点之一，也是最大的弱点。"市场不会因为你希望而改变。记住：小亏是成本，大亏是灾难。及时止损，保护本金，才有机会在下一次交易中赚回来。"感到自己做错了和决定平仓出市实际上是同一个过程。"

### Q4：如何识别市场的转折点？

**A4：** 利弗莫尔认为转折点通常有以下特征：
1. 价格创新高/新低，但成交量萎缩
2. 市场情绪极度乐观或悲观
3. 出现明显的技术形态（如头肩顶/底）
4. 大势与个股背离
5. 板块内某只股票拒绝跟进领头羊

### Q5：我应该全职交易吗？

**A5：** 在你能够稳定盈利之前，不要考虑全职交易。利弗莫尔说过："市场永远在那里，但你的本金不一定。"确保你有稳定的收入来源，交易只是你财富增长的一部分，而不是全部。利弗莫尔本人也经历过多次破产，证明即使是天才交易员也需要谨慎对待全职交易。

### Q6：如何对待朋友的交易建议？

**A6：** 利弗莫尔的惨痛教训：即使是最聪明、最可信的朋友也可能看错。在联合太平洋铁路事件中，他的朋友艾德·哈丁出于好意劝阻他，结果让他付出了4万美元的学费。利弗莫尔后来领悟："我对自己更有信心，我终于有能力摆脱那些过时的交易系统。"倾听可以，但决策必须基于自己的判断。

### Q7：为什么我的股票不涨，而同板块的其他股票都在涨？

**A7：** 利弗莫尔说："如果一只股票的价格表现不符合它当时所在市场的表现，即使在牛市行情中我也从来不会对这类股票有所青睐。"切斯特汽车的案例告诉我们：内部人可能在卖出，公司状况可能恶化。不要期待补涨，而应该警惕下跌。"这只股票一定有什么地方不对劲。"

### Q8：亏损后是否应该加仓摊低成本？

**A8：** 绝对不要！这是利弗莫尔最惨痛的教训之一。他在棉花期货上就是因为摊平亏损，最终损失了100万美元。他说："在所有投机性的大错误中，几乎没有什么错误比企图为已经亏损的交易降低平均成本的尝试更糟糕的了。"亏损时卖出，盈利时持有。
