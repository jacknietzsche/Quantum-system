# 股票大作手操盘术 - 可执行决策技能手册

> 来源：杰西·利弗莫尔《股票大作手操盘术》
> 适用对象：趋势交易者、中长线投资者
> 核心定位：基于时间与价格要素的机械化趋势跟踪体系

---

## 0. 思维链示例

### 0.1 案例分析场景：使用关键点方法判断买入时机

**场景描述：**
某股票当前价格25.00美元，在过去一段时间内于22.00-28.00美元区间震荡整理。通过行情记录分析，预期该股票将上涨至50.00美元。现在需要判断是否应该买入。

---

### 0.2 利弗莫尔经典关键点案例分析

#### 案例1：森蚺公司（Anaconda）突破100美元关键点

**案例背景：**
利弗莫尔观察到森蚺公司股价长期运行后，即将突破100美元这一关键点位。

**交易过程：**
- 当森蚺公司成交价冲过100美元时，利弗莫尔即刻下交易指令买进4000股
- 几分钟后，直至该股票价格穿越105美元，交易指令才完成（说明突破后快速上涨）
- 当天，它的成交价后来又上涨了10点
- 第二天又是一场不同凡响的膨胀过程
- 在短时间之内，这轮上涨行情持续伸展到明显高于150美元
- 中途仅有少数几次幅度为7到8点的正常的向下回撤过程
- 没有哪一次威胁到关键点100美元

**关键点理论提炼：**
> "当某只股票的成交价位于50、100、200甚至300美元时，一旦市场穿越这样的点位，则随后几乎总会无可避免地发生直线式的快速运动。"

---

#### 案例2：森蚺公司300美元关键点的危险信号

**案例背景：**
森蚺公司后续上涨至接近300美元，利弗莫尔准备再次使用关键点交易法。

**交易过程：**
- 当森蚺公司穿越200美元时，利弗莫尔成功地故伎重演
- 当它穿越300美元时，又再一次照搬此法
- 但这一次，它惯性上冲的幅度没有达到合适的程度
- 最高成交价只有302.75美元

**危险信号识别：**
- 市场变得很沉闷，几天之内都不活跃
- 该股票不但没有出现紧俏难买的现象
- 市场上反而充斥着大量供给
- 已经不能维持持续上涨的进程

**果断行动：**
- 利弗莫尔立即卖出8000股
- 其中5000股的卖出价是300美元
- 1500股的卖出价是299.75美元
- 这6500股是在不到2分钟的时间之内成交的
- 另外花了25分钟才卖出了剩余的1500股
- 成交价下降到298.75美元

**结果验证：**
- 第二天早晨，市场上掀起了一阵骚动
- 森蚺公司在伦敦市场一路下跌
- 纽约市场开盘时价格低了一大截
- 几天之后，它的成交价就降到了225美元

**核心教训：**
> "如果该股票在穿越关键点之后没有按照应有的模式运作，就是一个必须密切注视的危险信号。"

---

#### 案例3：伯利恒钢铁（Bethlehem Steel）1915年突破行情

**案例背景：**
1915年4月7日，伯利恒钢铁达到了创纪录的最高价位87.75美元。利弗莫尔判断当它突破100美元后将快速上涨。

**交易过程：**
- 4月8日，安排了第一份买入指令，拟从99到99.75美元逐步搜集筹码
- 同一日，该股票成交价一直上涨到117的高点
- 此后，它毫不停顿地一路飞涨
- 中途只有小幅的向下回撤
- 直至4月13日到达155美元为止
- 也就是突破关键点的5天之后

**盈利结果：**
- 从99美元买入点到155美元高点
- 5天内涨幅达56.5%
- 这轮涨势非常惊人

**核心洞见：**
> "如果某人耐心等待时机来利用关键点交易，就会获得巨大的回报。"

---

#### 案例4：可可期货1936-1937年关键点突破

**案例背景：**
1934年12月可可期权合约在2月达到当年最高价6.23美元，10月达到当年最低价4.28美元。
1935年在2月达到当年最高价5.74美元，6月达到当年最低价4.54美元。
1936年的最低价5.13美元是在3月达到的。

**关键变化：**
- 到了1936年8月，由于某种原因，可可市场完全变成了另一副模样
- 强烈的市场活动发生了
- 当月可可的成交价位于6.88美元
- 这一价位远远高于前两年的最高点（高于最近的两个关键点）

**后续行情：**
- 9月，可可成交价达到了7.51美元的高度
- 10月，最高价为8.70美元
- 11月，最高价为10.80美元
- 12月，11.40美元
- 1937年1月，创下了新的极端高位12.86美元
- 创造了一个历史纪录
- 在5个月的时间之内上涨了600点
- 中途仅有少数几次不足挂齿的正常回撤过程

**核心洞见：**
> "密切注视这些关键点，就为可可市场操作提供了绝佳机会。"

### 0.3 五步思考流程（基于利弗莫尔关键点理论优化）

```
【第一步：市场状态判断】
├─ 问题：当前市场是否处于可操作状态？
├─ 思考：整体市场环境是否支持投机操作？
├─ 利弗莫尔原则："有的市场条件下应当投机，有的市场条件下不应当投机"
├─ 判断依据：
│   ├─ 观察市场整体趋势
│   ├─ 观察成交量变化
│   ├─ 观察市场情绪
│   └─ 识别关键点形态是否形成
└─ 结论：[可操作 / 不可操作 → 空仓观望]

【第二步：行情记录分析 - 时间要素与价格要素融合】
├─ 问题：该股票的价格行为是否展现出可识别的模式？
├─ 思考：维持行情记录，观察价格行为特征和习性
├─ 利弗莫尔原则："我的准则将时间和价格二要素融为一炉"
├─ 分析内容：
│   ├─ 区间震荡时间：已持续多长时间？（时间要素）
│   ├─ 关键点位识别：
│   │   ├─ 历史高点/低点位置
│   │   ├─ 整数关口（50、100、200、300美元）
│   │   ├─ 前期密集成交区
│   │   └─ 新上市股票的历史最高价
│   ├─ 价格波动特征：上冲试探、下探支撑的表现
│   ├─ 成交量配合：是否有资金流入迹象？
│   └─ 形态识别：是否形成特定的价格形态？
└─ 结论：[发现关键点模式 / 继续观察]

【第三步：形成明确看法 - 独立判断】
├─ 问题：对该股票下一步重要动向是否有明确判断？
├─ 思考：基于行情记录，形成独立判断
├─ 利弗莫尔原则："投机其实就是预期即将到来的市场运动"
├─ 判断内容：
│   ├─ 预期方向：上涨至目标价位
│   ├─ 关键点位确定：
│   │   ├─ 入场关键点：突破历史高点/整数关口
│   │   ├─ 验证点位：突破后3点以上确认
│   │   └─ 目标价位：基于历史规律推算
│   ├─ 判断依据：区间突破、关键点信号
│   └─ 时间预期：大致的时间框架
└─ 结论：[形成看法 / 继续观察]

【第四步：等待市场验证 - 耐心守候】
├─ 问题：市场是否验证了你的看法？
├─ 思考：不要迫不及待地一头扎进去！
├─ 利弗莫尔原则："一定要找到基本的判断依据"
├─ 验证条件：
│   ├─ 价格突破关键点位（如100美元、历史高点）
│   ├─ 突破后上涨3点以上确认趋势
│   ├─ 成交量配合放大
│   ├─ 没有出现危险信号（如森蚺公司300美元案例）
│   └─ 突破后表现符合预期模式
├─ 利弗莫尔警示："只有到了这个时候，你才能'就市论市'地知道，你的想法已经被证实"
├─ 反面案例警示：
│   ├─ 森蚺公司300美元：突破后没有快速上涨，反而沉闷
│   └─ 危险信号：供给大量、不能维持上涨
└─ 结论：[等待验证 / 看法被否定 / 危险信号出现→退出]

【第五步：关键心理时刻入场 - 金字塔加码】
├─ 问题：是否到达关键心理时刻？
├─ 思考：市场运动力度是否足够强大？
├─ 利弗莫尔原则："当前市场运动的力度如此强大，它将率直地继续向前冲去"
├─ 入场策略：
│   ├─ 第一笔头寸：突破关键点时建立初始仓位
│   ├─ 金字塔加码：
│   │   ├─ 后续每一笔买进必须处在比前一笔更高的价位
│   │   ├─ 卖空时每一笔卖出必须处在比前一笔更低的价位
│   │   └─ 拉开战线，不要堆积在同一价位
│   ├─ 止损设置：亏损2个点立即警惕
│   └─ 仓位管理：每次只投入金额有限的一份资本
├─ 利弗莫尔洞见："这只股票之所以继续向前冲，不是因为我操作，而是因为它背后这股力量如此强大"
└─ 结论：[触发买入 / 继续等待]
```

### 0.4 关键点交易的具体操作规则

#### 规则1：整数关口关键点

**适用场景：**
股票成交价位于50、100、200甚至300美元等整数关口时。

**操作方法：**
- 一旦市场穿越这样的点位，随后几乎总会无可避免地发生直线式的快速运动
- 在突破瞬间立即下单买入
- 如森蚺公司突破100美元时立即买进4000股

**验证标准：**
- 突破后应当快速上涨10-15点
- 中途仅有正常的7-8点回撤
- 不能威胁到关键点位

---

#### 规则2：历史高点关键点

**适用场景：**
新股票上市2-3年内形成的历史最高价。

**操作方法：**
- 等待股票触及全新高位
- 突破历史高点时买入
- 如伯利恒钢铁突破87.75美元历史高点后冲向100美元

**验证标准：**
- 突破后快速脱离成本区
- 5天内可能出现大幅上涨（如伯利恒5天从99到155美元）

---

#### 规则3：下跌趋势反转关键点

**适用场景：**
股票在下降趋势中运行相当长时间后达到低位，随后形成回升行情。

**操作方法（以40美元低点案例为例）：**
- 股票从40美元低点回升到45美元
- 在几个点范围内横向波动几周
- 再次上涨至49美元
- 市场变得沉闷，几天之内都不活跃
- 持续下滑接近40美元关键点

**买入信号：**
- **情形A**：如果市场未能向下跌破40美元，一旦从当前向下回撤的低点开始上冲3点，就应该买进
- **情形B**：如果市场向下跌穿了40美元，但跌下去的幅度没有达到3点左右，那么一旦市场上涨至43美元，也应该买进

**目标价位：**
- 新趋势确认后将持续上涨，上升到另一个关键点49以上
- 比关键点高出3点或更多

---

#### 规则4：危险信号识别与退出

**危险信号（以森蚺公司300美元为例）：**
- 突破关键点后没有按照应有的模式运作
- 没有出现紧俏难买的现象
- 市场上反而充斥着大量供给
- 不能维持持续上涨的进程
- 最高成交价只有302.75美元（惯性上冲幅度不够）

**果断行动：**
- 立即卖出全部头寸
- 不要犹豫，不要希望
- 6500股在不到2分钟内成交
- 剩余1500股在25分钟内成交

**结果验证：**
- 第二天市场骚动
- 伦敦市场一路下跌
- 纽约开盘价格大降
- 几天后成交价降到225美元

### 0.5 怀疑点（自我质询清单）

在执行决策前，必须逐一回答以下怀疑点：

| 怀疑点 | 自我质询 | 警示语录 | 经典案例 |
|-------|---------|---------|---------|
| **怀疑1：市场状态** | 市场是否真的处于可操作状态？还是我急于入场而自我欺骗？ | "你可以赢一场马赛，但你不可能赢所有马赛" | 可可期货1934-1935年低位震荡时不操作 |
| **怀疑2：关键点确认** | 我识别的关键点是否准确？是否满足时间要素和价格要素的融合？ | "我的准则将时间和价格二要素融为一炉" | 森蚺公司100美元、伯利恒钢铁100美元 |
| **怀疑3：验证充分** | 市场是否真正验证了我的看法？突破后是否上涨3点以上？ | "千万不要迫不及待地一头扎进去" | 森蚺公司300美元突破后未验证 |
| **怀疑4：危险信号** | 是否出现危险信号？突破后表现是否符合预期模式？ | "如果该股票在穿越关键点之后没有按照应有的模式运作，就是一个必须密切注视的危险信号" | 森蚺公司300美元危险信号 |
| **怀疑5：时机正确** | 现在是否真的是关键心理时刻？还是过早入场？ | "一定要找到基本的判断依据" | 伯利恒钢铁等待3周后在99美元入场 |
| **怀疑6：情绪干扰** | 我是否被希望或恐惧情绪左右？ | "本该害怕的时候却满怀希望，本有希望的时候却惊惶不宁" | 300美元时该害怕却满怀希望 |
| **怀疑7：加码规则** | 是否遵循金字塔加码规则？每一笔是否比前一笔价位更高？ | "后续买进的每一笔必然处在比前一笔更高的价位上" | 利弗莫尔金字塔加码原则 |
| **怀疑8：风险准备** | 如果判断错误，我是否做好了止损准备？ | "利润总是能够自己照顾自己，而亏损则永远不会自动了结" | 亏损2个点立即警惕 |

### 0.6 最终决策关键

**决策流程总结：**

```
                    市场状态判断
                         │
           ┌─────────────┴─────────────┐
           │可操作                    │不可操作
           ↓                          ↓
      行情记录分析                  空仓观望
           │
           │发现关键点模式
           ↓
      形成明确看法
           │
           │确定关键点位
           ↓
      等待市场验证 ←←←←←←←←←←┐
           │                  │
           │验证通过          │未验证（继续等待）
           ↓                  │
      危险信号检查            │
           │                  │
           │无危险信号        │危险信号出现
           ↓                  ↓
      关键心理时刻判断        立即退出
           │                  │
           │时机成熟          │
           ↓                  │
      ┌────┴────┐             │
      │执行买入 │─────────────┘
      └─────────┘
           │
           ↓
      金字塔加码
           │
           ↓
      设置止损位（亏损2个点警惕）
           │
           ↓
      让利润奔跑
           │
           ↓
      危险信号出现时果断退出
```

**决策关键要点：**

1. **耐心是核心**："一分耕耘，一分收获，你的成功果实将与你在自己的努力中所表现出的真心和诚意直接成正比"

2. **关键点是基础**："不论何时，只要耐心等待市场到达我所说的'关键点'后才动手，我就总能从交易中获利"

3. **验证是前提**："只有到了这个时候，你才能'就市论市'地知道，你的想法已经被证实"

4. **危险信号必退出**："如果该股票在穿越关键点之后没有按照应有的模式运作，就是一个必须密切注视的危险信号"

5. **金字塔加码**："后续买进的每一笔必然处在比前一笔更高的价位上"

6. **止损是保障**："投机者不得不对当初的小额亏损采取止损措施来确保自己不会蒙受巨大损失"

7. **持有是利润来源**："真正从投机买卖中得来的利润，都来自那些从头开始就一直盈利的头寸"

## 1. 核心哲学与基本原则

- "今天，没有任何人或者任何组织能够人为制造行情、人为阻止行情"

## 2. 选股/标的决策树

### 2.1 标的选择流程

```
第一步：市场状态判断
    ↓ 判断当前市场是否处于可操作状态
    ↓ 有的市场条件下应当投机，有的市场条件下不应当投机
    ↓ "你可以赢一场马赛，但你不可能赢所有马赛"
    ↓ 是（可操作状态）→ 进入第二步
    ↓ 否 → 空仓观望

第二步：观察行情记录 - 寻找关键点
    ↓ 维持行情记录，记录价格变动
    ↓ 观察股票的价格行为特征和习性
    ↓ 寻找关键点位：
    │   ├─ 整数关口（50、100、200、300美元）
    │   ├─ 历史高点/低点
    │   ├─ 前期密集成交区
    │   └─ 新上市股票的历史最高价
    ↓ 发现关键点 → 进入第三步
    ↓ 未发现 → 继续观察

第三步：形成明确看法
    ↓ 就某个股票下一步的重要动向形成自己的判断
    ↓ "投机其实就是预期即将到来的市场运动"
    ↓ 确定入场关键点和目标价位
    ↓ 是 → 进入第四步
    ↓ 否 → 继续观察

第四步：等待市场验证
    ↓ 不要迫不及待地一头扎进去
    ↓ 等待价格突破关键点
    ↓ 观察突破后表现是否符合预期模式
    ↓ 检查危险信号
    ↓ 验证通过 → 进入第五步
    ↓ 未验证/危险信号 → 继续等待/退出

第五步：选择关键心理时刻入场
    ↓ "当前市场运动的力度如此强大，它将率直地继续向前冲去"
    ↓ 建立第一笔头寸
    ↓ 金字塔加码（每一笔比前一笔价位更高）
    ↓ 设置止损位
```

### 2.2 硬性指标清单

| 指标类型 | 具体要求 | 检查方式 |
|---------|---------|---------|
| 市场状态 | 处于可操作的市场条件 | 整体市场环境判断 |
| 关键点位 | 识别明确的整数关口或历史高低点 | 行情记录分析 |
| 时间要素 | 价格在关键区域整理足够时间 | 观察整理时间 |
| 明确看法 | 形成对下一步动向的判断 | 独立分析 |
| 市场验证 | 突破关键点后上涨3点以上 | 价格行为确认 |
| 无危险信号 | 突破后表现符合预期模式 | 观察突破后走势 |
| 关键时机 | 市场运动力度强大 | 趋势强度判断 |

### 2.3 一票否决红线

- ❌ 市场处于不可操作状态（胶着、超买、超卖）
- ❌ 没有识别出明确的关键点
- ❌ 关键点位未被市场验证就行动
- ❌ 突破后出现危险信号（如森蚺公司300美元案例）
- ❌ 急于求成，在关键时机到来前过早入场
- ❌ 被希望和恐惧情绪左右决策
- ❌ 没有维持行情记录，凭感觉交易
- ❌ 未遵循金字塔加码原则

## 3. 择时与买卖点判断规则

### 3.1 买入条件

**条件1：整数关口关键点买入**
- 股票成交价接近50、100、200、300美元等整数关口
- 等待价格穿越关键点位
- 突破后立即买入（如森蚺公司突破100美元时买入4000股）

**验证标准：**
- 突破后快速上涨10-15点
- 中途仅有7-8点的正常回撤
- 不威胁关键点位

**条件2：历史高点关键点买入**
- 新股票上市2-3年内形成历史最高价
- 等待价格突破历史高点
- 如伯利恒钢铁突破87.75美元后冲向100美元

**条件3：下跌趋势反转关键点买入**
- 股票在下降趋势中达到低位（如40美元）
- 形成回升行情后再次回落接近关键点
- **情形A**：未跌破关键点，从低点上冲3点时买入
- **情形B**：跌破关键点但幅度不足3点，上涨至关键点+3时买入

**条件4：关键心理时刻入场**
- 选择一个关键的心理时刻来投入第一笔交易
- "这个时刻是，当前市场运动的力度如此强大，它将率直地继续向前冲去"
- 股票必定已经进入了非常强势的状态

**条件5：从头开始就一直盈利的头寸**
- "真正从投机买卖中得来的利润，都来自那些从头开始就一直盈利的头寸"
- 如果股票买入后没有立即表现对头，考虑退出

### 3.2 卖出条件

**止损条件：**
- **小额亏损立即止损**
  - "投机者不得不对当初的小额亏损采取止损措施来确保自己不会蒙受巨大损失"
  - 亏损2个点就应该警惕
  - "在这两点的亏损之后，有可能雪上加霜，下一天再亏损两个点"
  - "这正是你应当害怕的时刻"

- **危险信号出现时果断退出**
  - "如果该股票在穿越关键点之后没有按照应有的模式运作，就是一个必须密切注视的危险信号"
  - 如森蚺公司300美元案例：突破后没有快速上涨，反而沉闷，供给大量
  - 立即卖出全部头寸，不要犹豫

- **利润不会自动了结**
  - "利润总是能够自己照顾自己，而亏损则永远不会自动了结"
  - 不要让小额亏损演变成巨大损失

**止盈条件：**
- **让利润奔跑**
  - "只要这个股票的表现对头，市场对头，就不要急于实现利润"
  - "让利润奔跑吧，你驾驭着它一起奔跑"
  - "也许它最终会扩大为一笔很可观的利润"

- **市场没有引起担心就继续持有**
  - "只要市场的表现没有任何迹象引起你的担心，那就鼓起勇气，坚定自己的信念，坚持到底"

**错误止盈的警示：**
- 在30.00美元买进，第二天急拉到32.00美元或32.50美元
- 立即变得充满恐惧，担心如果不把利润落袋为安，明天就会看着这利润化为乌有
- 于是卖出平仓，把这一小笔利润拿到手里
- "此时恰恰正是你该享受世界上一切希望的时刻！"
- "这两个点的利润昨天还不存在，为什么现在你担心丢掉这两个点的利润呢？"

### Q4：如何识别关键点？

**A4（基于利弗莫尔理念）：**

**整数关口关键点：**
- 股票成交价位于50、100、200、300美元时
- 一旦市场穿越这样的点位，随后几乎总会发生直线式的快速运动

**历史高低点关键点：**
- 新股票上市2-3年内形成的历史最高价或最低价
- 突破历史高点时买入，跌破历史低点时卖出

**下跌趋势反转关键点：**
- 股票在下降趋势中达到低位后回升
- 再次回落接近前期低点时观察
- 未跌破或跌破幅度不足3点时，上涨3点后买入

**行情记录方法：**
- "我的准则将时间和价格二要素融为一炉"
- 维持行情记录，亲手填写数字
- 观察价格行为特征和习性
- 寻找价格行为的重复或相似之处

### Q5：如何克服希望和恐惧？

**A5（基于利弗莫尔理念）：**

**认识问题：**
- "满怀希望是人类的显著特点之一，担惊受怕同样是另一个显著特点"
- "一旦你将希望和恐惧这两种情绪搅进投机事业，就会面临一个极可怕的危险"

**常见错误：**
- "你往往会被两种情绪搅糊涂了，从而颠倒了它们的位置"
- "本该害怕的时候却满怀希望，本有希望的时候却惊惶不宁"

**具体表现：**
- **该害怕时却满怀希望**：亏损时不止损，希望股价反弹（如深套时）
- **该持有时却惊惶不宁**：稍有盈利就急于卖出，害怕利润消失（如30美元买入32美元就卖出）

**克服方法：**
1. **维持行情记录**：用数据代替情绪
2. **识别关键点**：有明确的操作依据
3. **等待市场验证**：不凭感觉行动
4. **识别危险信号**：该害怕时果断退出
5. **让利润奔跑**：该持有时坚定持有
6. **培养耐心**："每次当我失去耐心，不是等待关键点到来的时机，而是胡乱交易企图快快获利的时候，就总是赔钱"

### Q6：如何进行金字塔加码？

**A6（基于利弗莫尔理念）：**

**核心原则：**
- "后续买进的每一笔必然处在比前一笔更高的价位上"
- "除非是在比前一笔更低的价位卖出，否则绝对不要再卖出下一笔"

**操作方法：**
- 第一笔：突破关键点时建立初始仓位
- 第二笔：价格比第一笔更高时买入
- 第三笔：价格比第二笔更高时买入
- 以此类推

**为什么要这样做：**
- "就我所知，如果遵循这一准则，比采取任何其他方法都能更加接近市场正确的一边"
- "你的头寸的确向你显示利润，这一事实就是证明你正确的有力证据"

**卖空时同样适用：**
- 每一笔卖出必须处在比前一笔更低的价位

**注意事项：**
- 拉开战线，不要堆积在同一价位
- 如果头笔交易已经处于亏损状态，绝不要继续跟进
- 绝不要摊低亏损的头寸
