# 不亏：职业投资人的股市生存之道 - 可执行决策技能手册

> 来源：资水、打新交朋友《不亏：职业投资人的股市生存之道》
> 适用对象：A股投资者、追求稳健收益的个人投资者
> 核心定位：以"不亏"为第一目标的系统性投资体系

---

## 思维链示例（Thinking Chain）

### 案例分析一：资水的分级A投资——"三个知道"的经典实践

**案例背景**：2015年6月，A股处于5000多点高位，资水在午休散步时顿悟"三个知道"原则，随后重仓分级A基金，在A股崩盘时赚得第一桶金。

**思考步骤**：

```
第一步：寻找"知道底、知道顶、知道时间"的标的
    → 问题：世界上最好的票是哪一只？
    → 答案：所有知道底、知道顶、知道时间的票都是最好的票
    → 分析分级A：底清清楚楚是0.78元，顶清清楚楚是0.92元
    → 时间：一年左右可实现18%的收益
    → 引用："只要在底部买入，在时间范围内耐心拿着，在顶部卖出，就是稳赚不亏的"

第二步：排雷检查（排除极端风险）
    → 分级A的本质是债券属性，有明确的回售价格支撑
    → 检查大盘位置：5000点处于历史高位，系统性风险极大
    → 但分级A与股市呈负相关，股市跌则分级A涨
    → "人多的地方不要去"——当时市场热点在股票，分级A被忽视

第三步：评估周期位置（大类资产轮动视角）
    → 股票周期：处于高位，即将进入衰退期
    → 分级A周期：处于低位，价值被严重低估
    → 流动性分析：M1-M2剪刀差显示流动性即将收紧
    → 决策：卖出股票类资产，买入分级A

第四步：计算风险收益比
    → 下行风险：从0.78元跌到0（极端情况），最大亏损100%
    → 但分级A有债底保护，实际下行空间有限
    → 上行空间：从0.78元到0.92元，收益18%
    → 风险收益比：约1:5，极具吸引力
    → "先求不亏，再求盈利"——债性保护提供了"不亏"的基础

第五步：仓位配置
    → 确定性极高：知道底、知道顶、知道时间
    → "我几乎用全部资金购买分级A"
    → 在A股从5000多点崩盘时，做分级A的人赚得盆满钵满

怀疑点验证：
    - 怀疑：是否过度集中？验证：分级A是类债券资产，分散在多个标的
    - 怀疑：是否会被政策改变规则？验证：当时分级基金规则稳定
    - 怀疑：是否买在高位？验证：0.78元是历史统计的明确底部

最终决策依据：
    → 完美符合"三个知道"：底（0.78元）、顶（0.92元）、时间（一年）
    → 大类资产轮动：股票高位→债券类资产低位
    → 风险收益比极佳：1:5
    → 结果：赚到了第一桶金
```

### 案例分析二：中远海控的周期投资——从"价量齐升"到景气高点识别

**案例背景**：2020年6月至2021年6月，海运价格大涨，中远海控股价从3.14元涨到33.4元，一年时间涨近10倍；2021年下半年海运价格下滑，股价同步下跌超过60%。

**思考步骤**：

```
第一步：识别行业景气度——"价量齐升"原则
    → 跟踪指标：集装箱运价指数（CCFI）
    → 价格维度：海运价格从2020年6月开始大幅上涨
    → 销量维度：受新冠疫情影响，海外生产停滞，海运需求大增
    → 逻辑链条：疫情→海外停工→海运需求大增→运价大涨6倍→中远海控年利润翻9倍
    → "变化一影响一业绩一股价"的因果积累

第二步：判断周期位置
    → 供给端：造船产能有限，短期内无法快速扩张
    → 需求端：疫情导致的特殊需求爆发
    → 判断：行业进入景气周期，处于"发展—高潮"阶段
    → 引用："判断一个行业景气度已经上升而且可持续，但股价还没有作出充分反应，才是找出未来大牛股的基本逻辑"

第三步：排雷检查
    → 商业逻辑：海运价格暴涨，企业盈利暴增，逻辑通顺
    → 质疑声音：关注投资论坛是否有专业投资者提出疑问
    → 交易所问询：检查是否有异常问询
    → 股权结构：国企背景，无治理问题

第四步：评估"三个知道"
    → 知道底吗？知道——2020年6月海运价格处于周期底部
    → 知道顶吗？大致知道——海运价格不可能无限上涨，历史周期显示有顶
    → 知道时间吗？不确定——疫情持续时间未知
    → 确定性评估：知道两个（底和顶），中等确定性

第五步：买入与卖出的时机把握
    → 买入时机：2020年6月，价量齐升初期，股价3.14元
    → 持仓跟踪：持续监测海运价格指数
    → 卖出信号：2021年下半年海运价格开始下滑
    → 关键认知："市场里的定价权资金，并不是盯着企业的财务数据来操作股票的，而是盯着景气周期来操作的"
    → 财务数据滞后：2022年中报业绩最好时，股价已从高点跌去60%

怀疑点验证：
    - 怀疑：是否买在景气高点？验证：2020年6月是底部，不是高点
    - 怀疑：周期何时结束？验证：持续跟踪运价指数，价格下滑即卖出
    - 怀疑：财务数据好为何股价跌？验证：股价领先财务数据，看周期不看财报

最终决策依据：
    → 价量齐升确认景气周期
    → 知道底，大致知道顶，中等确定性
    → 在周期底部买入，在景气高点前卖出
    → 核心教训："从企业历史的盈利数据，线性外推企业未来几年的盈利数据，往往是不准确的"
```

### 案例分析三：打新交朋友的可转债杠杆操作——规则确定性与极限风险控制

**案例背景**：2014年，打新交朋友在可转债市场使用杠杆，在一天内实现翻倍收益，但也经历了巨大的心理煎熬。

**思考步骤**：

```
第一步：识别规则确定性
    → 可转债规则："下有保底"——债券性质提供债底保护
    → 回售条款：进入回售期，回售价格成为有力支撑
    → 到期兑付：临近到期，债底价格变成强支撑
    → 历史验证：A股散户可买的可转债尚未出现违约
    → "对于发行转债的公司，要么还钱，要么转股"

第二步：评估标的——中行转债案例分析
    → 价格：100元面值以下还在折价
    → 债底计算：1.76年的中行纯债极限值是98元（按金融债5%贴现）
    → 不是93元，所以不会爆仓
    → 排除其他品种：平安转债、工行转债进攻性强但可能爆仓

第三步：杠杆使用的极限风险考量
    → 融资成本：借1000万元，一年利息74万元，一天2000多元
    → 策略优化：
        - 不能太早上杠杆，单付利息就得爆仓，必须等
        - 金融股PB已低到极致，两年ROE大概率推动股价上涨
    → "高杠杆交易如同在万米高楼的边缘行走，比的不是跑步能力，而是心态"

第四步：仓位管理与心理承受
    → 持仓体验："可转债波动不大，有时会涨1%，但只要有一天跌2%，就相当于连续跌停"
    → 心理煎熬：起起落落过程中的滋味，没有身临其境很难体会
    → 关键节点：靠近年底时，一天涨10%以上，实现翻倍
    → 卖出策略：130元开始卖出，160元左右卖光（后来涨到190多元）

第五步：验证与调整
    → 验证规则：可转债的债底保护是否有效？有效
    → 验证杠杆：是否在最不情愿的时候交出廉价筹码？没有
    → 调整策略：130元开始分批卖出，不贪图最后一段利润

怀疑点验证：
    - 怀疑：杠杆是否过高？验证：计算了极限风险，债底98元提供保护
    - 怀疑：是否会爆仓？验证：排除了可能爆仓的品种，选择最安全的
    - 怀疑：是否应该继续持有？验证："你赚你的，我赚我的"，不贪图最后一段

最终决策依据：
    → 规则确定性：可转债"下有保底"特性
    → 极限风险控制：计算债底，排除爆仓可能
    → 分批建仓与卖出：控制风险，锁定利润
    → 核心教训："即使下定决心'赌'了，也不是那么轻轻松松就能成功的"
```

### 案例分析四：德国30 QDII事件驱动投资——哲学认知与预期前置

**案例背景**：2020年4-5月，新冠疫情全球暴发，全球股市暴跌。资水在5月海外疫情最恐慌时刻，重仓德国30 QDII（513030），大赚一笔。

**思考步骤**：

```
第一步：重大事件分析
    → 事件：新冠疫情全球暴发，全球股市暴跌
    → 市场情绪：极度恐慌，海外疫情最严重
    → 常规反应：卖出避险

第二步：哲学层面的认知
    → 核心理念："人定胜天"
    → 逻辑：每次碰上天灾人祸，组织起来的人类是世界上压倒一切的、最伟大的力量
    → 判断：疫情被克服只是时间问题
    → "事件驱动考验的是投资者在哲学、社会、经济、管理者价值观等方面的深刻理解和认知"

第三步：评估"三个知道"
    → 知道底吗？大致知道——疫情最恐慌时往往是市场底部
    → 知道顶吗？不知道——取决于疫情发展
    → 知道时间吗？大致知道——疫情终将被克服
    → 确定性评估：知道底和时间，不知道顶，中等确定性

第四步：选择标的
    → 德国30 QDII（513030）：代表欧洲核心资产
    → 选择逻辑：欧洲疫情严重但终将恢复，优质资产被错杀
    → 时机：5月，市场最恐慌时刻

第五步：仓位与持有
    → "重仓"——基于哲学认知的确定性
    → 持有：等待疫情被克服
    → 结果：大赚一笔

怀疑点验证：
    - 怀疑：疫情是否会长期持续？验证：基于"人定胜天"的哲学判断
    - 怀疑：欧洲经济是否会崩溃？验证：选择核心资产，抗风险能力强
    - 怀疑：是否抄底过早？验证：5月是最恐慌时刻，符合"人弃我取"

最终决策依据：
    → 哲学认知："人定胜天"
    → 事件驱动：疫情最恐慌时刻
    → 标的确定性：德国核心资产
    → 核心教训："永远要比别人预期在前面"
```

### 案例分析五：锂化工产业投资——"7倍因子"与涨价题材跟踪

**案例背景**：2019-2022年，受新能源汽车强劲需求影响，锂化工产业呈现价量齐升，碳酸锂价格从2021年7月的9万元/吨涨到2022年11月的59万元/吨，天齐锂业、赣锋锂业等涨幅近10倍。

**思考步骤**：

```
第一步：识别"价量齐升"
    → 量的方面：2019-2022年全球碳酸锂需求量从33.16万吨增至70万吨，预计2025年达150万吨
    → 价的方面：碳酸锂价格从9万元/吨涨至59万元/吨
    → "价量齐升，行业进入景气周期"

第二步：理解"7倍因子"
    → 案例分析：A公司毛利率35%，产品涨价10%，利润增长超过70%
    → 原理：产品价格和销量是最核心的财务指标
    →  especially产品价格对利润影响显著——"7倍因子"
    → 不同行业影响不同：毛利率越高，价格影响越小（如茅台毛利率92%，价格只是1倍因子）

第三步：专业投资者的敏感度
    → "有一部分牛散专门做涨价题材，长期跟踪某些产品价格"
    → 密切关注价格变化的持续时间和背后的原因
    → 通过判断行业景气周期来投资

第四步：回答"股票为什么上涨"
    → 向专业投资者提问，得到七八条答案
    → 其中必然有一条："它在涨价"

第五步：周期位置判断与买卖时机
    → 买入：2021年7月之前，涨价初期
    → 跟踪：持续监测碳酸锂价格走势
    → 卖出：2022年11月价格见顶后
    → 核心认知："景气高点的股票，跌幅可能高达60%-80%"

怀疑点验证：
    - 怀疑：涨价是否可持续？验证：跟踪需求增长和产能扩张
    - 怀疑：是否买在高点？验证：2021年7月是涨价初期，不是高点
    - 怀疑：何时卖出？验证：价格开始下跌即卖出，不贪图最后一段

最终决策依据：
    → 价量齐升确认景气周期
    → "7倍因子"显示利润弹性巨大
    → 持续跟踪产品价格
    → 核心教训：专业投资者对产品价格变动极其敏感
```

### 通用思维链模板：评估一个投资机会的确定性

**场景**：用户问"这只股票/这个投资机会现在可以买入吗？"

**思考步骤**：

```
第一步：排雷检查（先排除风险）——"一票否决"原则
    → 是否有人质疑？投资论坛是否有专业投资者提出疑问？
    → 交易所是否反复问询？
    → 商业逻辑是否通顺？
        - 大存大贷？（一边大额存款一边大额贷款）
        - 一边分红一边融资？
        - 毛利率异常高于同行？
    → 股权结构是否有问题？
        - 个人绝对控股？
        - 家族控股？
        - 两股东内斗？
    → 业务是否靠谱？
        - 新业务缺乏可行性？
        - 过度多元化？
    → 地域和行业风险：
        - 造假高发地域要小心（经济不景气、法治不健全地区）
        - 造假高发行业要小心（农业、生物资产等难以审计行业）
    → K线图是否有庄股嫌疑？（走势独立于大盘、毛刺多）
    → 如果任何一项有问题，一票否决
    → "人多的地方不要去"——是否处于热点炒作中？

第二步：判断"三个知道"（评估确定性）——核心决策框架
    → 知道底吗？
        - 估值是否处于历史低位？
        - 周期是否处于底部？
        - 是否有债底/回售价等硬性支撑？
    → 知道顶吗？
        - 预期空间有多大？
        - 景气高点在哪里？
        - 历史估值上限是多少？
    → 知道时间吗？
        - 催化剂何时出现？
        - 政策节奏如何？
        - 到期/回售时间？
    → 确定性评估：
        - 三个都知道 = 高确定性（可以重仓）
        - 知道两个 = 中等确定性（中等仓位）
        - 知道一个 = 低确定性（轻仓试水）
        - 三个都不知道 = 确定性很低（不操作）
    → "投资的'三个知道'——知道底、知道顶、知道时间"

第三步：评估周期位置（把握大势）——"万物皆有周期"
    → 大盘周期：
        - 五个维度：估值、情绪、资金、政策、技术
        - 流动性：M1-M2剪刀差、10年期国债收益率
        - 估值：PE/PB历史分位
        - 情绪：换手率、融资余额、市场普遍预期
        - 政策：货币政策、监管政策
        - 重大事件：是否有突发重大事件？
    → 行业周期：
        - "价量齐升"判断行业景气度
        - 产品价格走势
        - 销量/需求变化
        - 库存和产能变化
        - 行业政策影响
    → 个股周期：
        - 处于什么阶段？（潜伏—发展—高潮—衰退—沉寂）
        - 预期是否已兑现？
    → "万物皆有周期，潜伏—发展—高潮—衰退—沉寂"

第四步：计算风险收益比（量化决策）——"先求不亏，再求盈利"
    → 下行风险是多少？
        - 止损位设在哪里？
        - 最大亏损幅度？
        - 是否考虑极限风险？
    → 上行空间是多少？
        - 目标位在哪里？
        - 预期收益率？
    → 风险收益比 ≥ 1:2 才考虑
    → 引入"到期收益率"概念：
        - 把未来状况清晰描述
        - 判断某一时点的股价
        - 持仓不再迷惘

第五步：仓位配置（根据确定性分配）——"能力圈原则"
    → 确定性高（三个都知道）→ 重仓（可达80%）
    → 确定性中等（知道两个）→ 中等仓位（30-50%）
    → 确定性低（知道一个）→ 轻仓（10-20%）或放弃
    → 能力圈内：配置主要仓位保持不亏
    → 能力圈外：小仓位试错锻炼提高
    → 总仓位不超过80%，保留20%现金
    → 单一标的不超过总资产的20%
    → 单一行业不超过总资产的30%
    → "在能力圈内配置主要仓位保持不亏，在能力圈外小仓位试错"

第六步：制定买卖计划
    → 买入计划：
        - 首次建仓不超过计划仓位的30%
        - 下跌10%加仓30%
        - 再下跌10%加满
        - 每次加仓前重新评估逻辑
    → 卖出计划：
        - 逻辑止损：买入逻辑被证伪，立即止损
        - 风控止损：单笔亏损达到预设上限（如-10%）
        - 止盈：预期兑现、景气高点、估值极值
        - 移动止盈：盈利后止损上移至成本价

怀疑点清单（自我质疑）：
    - 我是否被"业绩优良"的表象迷惑？
        → "如果总也不发光，凭什么让人相信它是金子"
    - 是否买在景气高点？
        → "为宴席买单"——景气高点的股票不买
    - 是否过度自信？
        → "为何总以为身边的人们都是瞎子"
    - 是否被"低估值"陷阱误导？
        → "变化比估值更重要"——估值是静态水位，不指明方向
    - 是否忽视了政策风险？
        → "政策是市场背后的手"
    - 是否考虑了极限风险？
        → "高杠杆交易如同在万米高楼的边缘行走"

最终决策关键：
    → 排雷通过 + 三个知道至少两个 + 风险收益比达标 = 可以考虑买入
    → 分批建仓，严格执行买卖计划
    → 否则，耐心等待——"知道未来，才能在当下盈利"
    → "每年投资都不亏，十年下来就财务自由了"
```

## 1. 核心哲学与基本原则

### 1.1 市场世界观

**原则1：不亏是第一要务，盈利是第二目标**
- "不亏"不是绝对不亏损，而是一种意识、一种理念
- 做每笔交易时都仔细评估风险和收益，在做好防守的基础上追求进攻
- 不管牛市、熊市，都实现复利增长、不大幅回撤
- 核心地位：这是整个投资体系的基石，"每年投资都不亏，十年下来就财务自由了"

**原则2：建立自己的优势，在能力圈内投资**
- 投资的本质是竞争，竞争中的生存之道就是建立优势
- 能力圈内就是具有确定性优势的地方
- 在能力圈内配置主要仓位保持不亏，在能力圈外小仓位试错锻炼提高
- 核心地位：这是实现"不亏"的核心路径

**原则3：确定性有三个来源——价值、周期、规则**
- 价值产生确定性：价格围绕价值波动
- 周期产生确定性：万物皆有周期，"潜伏—发展—高潮—衰退—沉寂"
- 规则产生确定性：规则是个人投资者最容易掌控的确定性来源
- 核心地位：这是寻找投资机会的方法论

**原则4：投资的"三个知道"——知道底、知道顶、知道时间**
- 三个选项都知道，交易具有很高的确定性
- 只知道两个或一个选项，也提高了交易的确定性
- 三个选项都不知道，交易的确定性就很低
- 核心地位：这是评估交易确定性的核心标准

**原则5：没有一条弯路是白走的**
- 投资如同走迷宫，不把死胡同蹚出来打上标记，不容易找到真正出路
- 资本市场所有理论都有严格的适用条件，不存在简单的对错和绝对的真理
- 把各种套路融会贯通，就可以用得风生水起
- 核心地位：这是持续进步的心态基础

**原则6：变化比估值更重要**
- 估值是静态水位，不指明方向
- 估值说明的是企业现状，不是企业变化
- 在A股，定价权资金可以长期让估值处于偏离状态
- 核心地位：这是分析股票的核心视角

## 2. 选股/标的决策树

### 2.1 标的选择流程

```
第一步：判断大盘周期位置
    ↓ 从五个维度判断大盘周期（估值、情绪、资金、政策、技术）
    ↓ 大盘处于低位或上升初期 → 进入第二步
    ↓ 大盘处于高位或下降期 → 空仓观望或降低仓位

第二步：选择资产类别
    ↓ 根据周期选择大类资产（股、债、商品）
    ↓ 哪个见底了就买哪个（大类资产轮动）
    ↓ 是 → 进入第三步

第三步：行业景气度判断
    ↓ 从"价量齐升"判断行业景气度
    ↓ 选择景气度向上或即将反转的行业
    ↓ 是 → 进入第四步
    ↓ 否 → 排除该行业

第四步：个股筛选（排雷）
    ↓ 检查是否符合商业逻辑
    ↓ 检查是否有人质疑、交易所问询
    ↓ 检查股权结构、业务靠谱程度
    ↓ 是 → 进入第五步
    ↓ 否 → 一票否决

第五步：预期管理评估
    ↓ 判断股票类型（缓慢增长/稳定增长/快速增长/周期型/困境反转/隐匿资产）
    ↓ 评估预期收益和风险
    ↓ 是 → 纳入观察名单
    ↓ 否 → 继续观察
```

### 2.2 硬性指标清单

| 指标类型 | 具体要求 | 检查方式 |
|---------|---------|---------|
| 大盘位置 | 处于估值低位或情绪低位 | 检查PE分位、换手率、融资余额等 |
| 行业景气 | 价量齐升或周期底部 | 检查产品价格、销量、库存数据 |
| 商业逻辑 | 符合基本商业常识 | 检查毛利率、现金流、应收账款等 |
| 股权结构 | 股权分散或国资控股 | 避免个人绝对控股、家族控股 |
| 预期收益 | 风险收益比 ≥ 1:2 | 计算"三个知道" |

### 2.3 一票否决红线（排雷清单）

**必须规避的情形：**

| 序号 | 红线情形 | 判断依据 |
|-----|---------|---------|
| 1 | 景气高点的股票不买 | 一两年内涨了5-10倍，透支今后数年预期 |
| 2 | 不符合商业逻辑的不买 | 大存大贷、一边分红一边融资、毛利率异常高于同行 |
| 3 | 有人质疑的不买 | 投资论坛有专业投资者提出疑问 |
| 4 | 交易所反复问询的不买 | 交易所发问询函提示风险 |
| 5 | 股权结构有问题的不买 | 个人绝对控股、家族控股、两股东内斗 |
| 6 | 业务不靠谱的不买 | 新业务缺乏可行性、过度多元化 |
| 7 | 造假高发地域要小心 | 经济不景气、法治不健全地区 |
| 8 | 造假高发行业要小心 | 农业、生物资产等难以审计行业 |
| 9 | K线图有庄股嫌疑要小心 | 走势独立于大盘、毛刺多 |

## 3. 择时与买卖点判断规则

### 3.1 买入条件

**条件1：大盘周期配合**
- 大盘处于估值低位（PE低于历史均值）
- 市场情绪低迷（换手率低、融资余额低）
- 政策开始转向积极

**条件2：行业/标的周期见底**
- 产品价格处于周期底部
- 库存开始下降、销量开始回升
- 行业政策开始支持

**条件3：预期差机会**
- 利好尚未被市场充分认知
- 比市场预期早一步布局
- "永远要比别人预期在前面"

**条件4：分批建仓**
- 首次建仓30%计划仓位
- 下跌10%加仓30%
- 再下跌10%加满
- 每次加仓前重新评估逻辑

### 3.2 卖出条件

**止损条件：**
- **逻辑止损**：买入逻辑被证伪，立即止损
- **风控止损**：单笔亏损达到预设上限（如-10%）
- **发现更好的机会**：换仓

**止盈条件：**
- **预期兑现**：利好兑现，且后面没有更大的利好，立即出货
- **景气高点**：行业景气达到高点，产品价格开始下跌
- **估值极端**：估值达到历史极值，风险收益比不再有利

**移动止盈：**
- 盈利后，止损上移至成本价
- 使用移动平均线或技术支撑跟踪

### 3.3 仓位管理规则

**资产分类与配置：**

| 资产类别 | 具体品种 | 风险特征 | 建议仓位 |
|---------|---------|---------|---------|
| 股性权益类 | 股票、ETF、期货 | 高贝塔，高波动 | 根据能力圈配置 |
| 非线性权益类 | 可转债、期权组合 | 风险介于股债之间 | 中等仓位 |
| 债性投资类 | 债券、理财、套利 | 低风险，确定性高 | 主要仓位 |

**仓位管理原则：**
- **确定性原则**：在能力圈内投资，确定性高的多配，确定性低的少配
- **周期原则**：卖出高估的，买入低估的，实现动态再平衡
- **风险边界原则**：投资风险由投资组合结构决定，能力不能控制风险

**具体仓位建议：**
- 总仓位不超过80%，保留20%现金应对机会和风险
- 单一标的不超过总资产的20%
- 单一行业不超过总资产的30%
- 高风险标的（期货、期权）仓位严格限制

## 4. 风险控制与心态纪律

### 4.1 风控铁律

| 规则 | 具体要求 | 违反后果 |
|-----|---------|---------|
| 排雷机制 | 每笔交易前检查排雷清单 | 踩雷风险 |
| 分仓机制 | 单一标的≤20%，单一行业≤30% | 集中风险 |
| 杠杆限制 | 融资杠杆≤1.5倍，期货轻仓 | 爆仓风险 |
| 止损纪律 | 单笔亏损≤总资金5% | 深套风险 |
| 黑天鹅防范 | 永远假设极端情况会发生 | 致命损失 |

**杠杆使用的铁律：**
- 杠杆必须考虑极限风险
- 融资杠杆：避免在最不情愿的时候交出廉价筹码
- 期货杠杆：轻仓参与，做好爆仓心理准备
- "高杠杆交易如同在万米高楼的边缘行走，比的不是跑步能力，而是心态"

### 4.2 心理建设方法

**调整投资心态的四个方法：**

**方法1：学习行为经济学和心理学**
- 阅读《思考快与慢》《乌合之众》
- 理解锚定效应、损失厌恶、近因效应、均值回归
- 树立正确的投资价值观

**方法2：认清自我，顺应情绪**
- 承认人的性格和风险偏好不同
- 持仓应该保持舒服的状态
- 产生焦虑就分析逻辑起点，有担忧就解决
- "跌10个点不舒服了，告诉自己还能忍，然后跌30个点甚至50个点后忍不住才割——这是错误的"

**方法3：充分借助工具控制情绪**
- 数据：用集思录等数据作为尺子
- 模型：建立快速反应的模型框架
- 规则：依据常识控制情绪

**方法4：认知与情绪的正反馈**
- 焦虑源于认知不足
- 用焦虑推动反馈改进，拓展认知
- "认知修炼，目标是将大脑中的羊肠小道拓展成高速公路"

### 4.3 禁忌行为清单

- ❌ 追热点、炒概念（"人多的地方不要去"）
- ❌ 使用高杠杆（超过1.5倍融资或期货重仓）
- ❌ 满仓操作（不留现金应对）
- ❌ 频繁交易（背负高额交易成本）
- ❌ 听消息炒股（丧失独立思考能力）
- ❌ 盲目跟大V（构建互毁模式）
- ❌ 亏损加仓摊低成本（越陷越深）
- ❌ 买在景气高点（为宴席买单）
- ❌ 买不符合商业逻辑的股票（财务造假风险）

## 5. 作者理论的适用边界与局限性

### 5.1 适用市场环境

**最适合的市场：**
- ✅ A股市场：散户多、波动大、政策影响明显
- ✅ 周期性市场：有明确的底和顶，便于"三个知道"
- ✅ 有规则红利的市场：如可转债、打新等

**A股市场的独特优势：**
1. 周期性明显，每隔几年回到原点，提供低位重仓机会
2. 涨跌停板和T+1保护，踩雷有逃命机会
3. 退市少，重组多，再差的股可能起死回生
4. 散户多，对手盘相对较弱
5. 成交活跃，各种策略有用武之地

**不适合的市场：**
- ❌ 美股长牛：风险暴露不出来，不敢重仓
- ❌ 极端震荡市：没有明确方向
- ❌ 流动性枯竭的市场：无法顺利进出

### 5.2 对投资者的要求

**知识要求：**
- 懂宏观、懂政策、懂行业、懂经营、懂财务
- 懂风控、懂技术、懂统计、懂哲学、懂博弈
- "这其实是一套大学的本硕博课程，没有捷径"
- 需要十年之功、历经两轮以上牛熊

**性格要求：**
- 能够独立思考、独立学习
- 能够承受波动而不焦虑
- 有耐心，能够等待机会
- 能够诚实面对自己，承认错误

**资金要求：**
- 不需要巨额资金，但需要稳定资金
- 不需要从账户提取资金维持生活
- 能够承受一定回撤而不影响心态

### 5.3 方法盲点

**作者承认的局限：**
1. **策略失效风险**：低风险策略会随着市场变化而失效
   - 如分级基金折溢价套利、市值打新等已失效
   - 需要不断学习、构建新策略

2. **能力圈限制**：每个人都有认知边界
   - 不可能精通所有领域
   - 需要在能力圈内投资，同时不断扩展

3. **黑天鹅风险**：极端事件无法预测
   - 丹尼斯、LTCM都因黑天鹅清盘
   - 只能通过风控降低影响

**实践中的问题：**
1. **学习曲线陡峭**：需要掌握庞大的知识体系
2. **时间成本高**：需要十年之功才能入门
3. **独立学习能力稀缺**："大概十人中仅有一人具备"

## 6. 可定制化问答语料库

### Q1：这只股票基本面很好，但价格一直在跌，该买入吗？

**A1（基于《不亏》理念）：**

> "如果总也不发光，凭什么让人相信它是金子！"

首先检查以下几点：

1. **大盘周期位置**：大盘是处于低位还是高位？如果大盘处于下降趋势，个股很难独善其身。

2. **行业景气度**：行业是否处于景气下行期？即使是好公司，行业下行时也会下跌。

3. **估值水位**：当前估值是否真的便宜？是否达到历史低位？还是只是"看起来便宜"？

4. **预期管理**：这只股票属于哪种类型？
   - 缓慢增长型：不要期望大涨，适合做防守
   - 周期型：可能在景气底部，可以埋伏
   - 困境反转型：需要判断能否走出困境

5. **排雷检查**：是否有人质疑？交易所是否问询？股权结构是否有问题？

**决策原则：**
- 如果大盘、行业都在下行，先观察，不要急于抄底
- 如果排雷通过、估值处于历史低位、行业有反转迹象，可以分批建仓
- "变化比估值更重要"，关注是否有新的变化出现

---

### Q2：持有的股票已经盈利50%，该卖出吗？

**A2（基于《不亏》理念）：**

> "永远要比别人预期在前面"

检查以下几点：

1. **预期是否兑现**：买入时的利好是否已经兑现？后面还有更大的利好吗？
   - A股的行为模式是"炒预期"，"一旦利好兑现，且后面没有更大的利好，就要立即出货"

2. **景气位置**：行业景气是否达到高点？
   - 产品价格是否开始下跌？
   - 库存是否开始上升？
   - "景气高点的股票，跌幅可能高达60%-80%"

3. **估值位置**：估值是否达到历史极值？
   - 如果估值已经远超历史均值，风险收益比不再有利

4. **股票类型**：
   - 快速增长型：高速发展是否接近尾声？
   - 周期型：景气周期是否接近顶部？

**决策原则：**
- 如果预期兑现、景气高点、估值极值，三者满足其一，考虑减仓
- 如果三者都满足，坚决卖出
- "你赚你的，我赚我的"，不要贪图最后一段利润

---

### Q3：如何判断大盘的周期位置？

**A3（基于《不亏》理念）：**

从五个维度判断大盘周期：

1. **估值维度**：
   - 全市场PE、PB是否处于历史低位？
   - 股息率是否高于无风险收益率？

2. **情绪维度**：
   - 换手率是否低迷？
   - 融资余额是否下降？
   - 市场是否普遍悲观？

3. **资金维度**：
   - 北向资金、机构资金是否流出？
   - 成交量是否萎缩？

4. **政策维度**：
   - 货币政策是否宽松？
   - 监管政策是否支持市场？
   - 是否有重大改革利好？

5. **技术维度**：
   - 是否跌破重要支撑位？
   - 是否出现底部形态？

**综合判断：**
- 五个维度都指向低位：历史大底，可以重仓
- 三四个维度指向低位：相对底部，可以加仓
- 只有一两个维度指向低位：继续观察

---

### Q4：被深套了怎么办？

**A4（基于《不亏》理念）：**

> "没有一条弯路是白走的"

**第一步：检查买入逻辑是否还成立**

- 当初买入的理由是什么？
- 这些理由是否被证伪？
- 如果逻辑被证伪，坚决止损，不要犹豫

**第二步：检查是否触发排雷清单**

- 是否发现了新的问题（财务造假、治理问题等）？
- 如果发现问题，立即止损

**第三步：评估持仓结构**

- 这只股票占仓位多少？
- 如果仓位过重，考虑减仓至舒服的状态
- "好的持仓应该是舒服的状态，如果产生焦虑，多半是有超出自己能力范围的事情"

**第四步：重新评估预期**

- 这只股票现在属于什么类型？
- 预期收益和风险是否还合理？
- 是否有更好的机会可以换仓？

**核心原则：**
- "亏损不是坏事，亏着亏着，就把问题想明白了"
- 但要确保亏损在可控范围内，不影响整体账户
- 单笔亏损超过总资金5%，必须止损

---

### Q5：如何扩展自己的能力圈？

**A5（基于《不亏》理念）：**

扩展能力圈的四步口诀：**观摩别人套路，思考背后根因，小仓试错调整，重仓决战获利。**

**第一步：观摩别人套路**
- 关注盈利者的交易记录和年度总结
- 关注知名连载帖（如银行股轮动、可转债轮动等）
- "别人总会泄露一点出来，需要保持极度的敏锐性"

**第二步：思考背后根因**
- 别人挣钱的原理是什么？
- 有哪些假设前提？
- 这些前提现在还成立吗？
- "细细揣摩其中的窍门"

**第三步：小仓试错调整**
- 拿2%-5%的资金专门试错
- 实战得来的经验比书本深刻得多
- "亏损经历都是宝贵的财富"

**第四步：重仓决战获利**
- 理论和实战都完善后，可以重仓
- "何以暴富？唯有重仓"
- 但前提是确定性足够高

**重要提醒：**
- 扩展能力圈是在主仓不亏的基础上进行的
- 不要因为扩展能力圈而影响主仓的安全性
- "一招鲜注定不能吃遍天，投资者必须不停地扩展能力圈"

### Q6：技术分析有用吗？

**A6（基于《不亏》理念）：**

**核心结论：根据技术指标炒股，将获得市场平均收益。**

也就是说，无论采用什么技术指标，如果像计算机一样严格操作，最终收益率跟持股不动是一样的。

**但技术分析有两个用途：**

**用途1：K线图的本质是买卖双方博弈的轨迹**
- 从K线图提炼的信息，第一步结论只能是多空博弈
- 第二步才是从博弈推演出走势
- 跳过博弈直接推演走势，是逻辑跳跃，不靠谱

**用途2：利用技术指标进行验证**
- 根据市场各方博弈判断走势
- 如果技术指标匹配设想的走势，说明分析暂时准确
- 如果不匹配，说明有新因子未考虑到，需要调整

**职业投资人的用法：**
- 看K线，看到的全是多空双方博弈
- 建立"预判—验证—调整"的迭代模式
- 使判断与市场保持同步

**切记：**
- 技术分析的门槛最低，如果某个指标有效，无数人会用，直到失效
- 不要被"支撑位""阻力位""背离"等名词迷惑
- 做简单统计就会发现，支撑位从来就不是支撑位

### Q7：A股和其他市场有什么区别？

**A7（基于《不亏》理念）：**

**最大的区别：A股根据预期甚至是想象空间进行交易，其他市场根据确切的信息进行交易。**

**A股的炒作周期：**
1. 潜伏阶段：股票对利空钝化，先知先觉资金入场
2. 拉升阶段：利好传闻出现，股价大幅拉升
3. 盘整阶段：利好确认，股价反而不再大涨
4. 杀跌阶段：利好兑现，股价大跌

**操作原则：**
- "永远要比别人预期在前面"
- 建仓要比大众更早预判利好
- 出货要在利好兑现时立即行动

**A股的优势：**
1. 周期性明显，提供低位重仓机会
2. 涨跌停板保护，踩雷有逃命机会
3. 散户多，对手盘相对较弱
4. 成交活跃，策略有用武之地

**结论：在A股挣钱的难度比外盘低很多，在A股没挣到钱，在其他市场更难生存。**

### 确定性的三个来源

| 来源 | 说明 | 适用策略 |
|-----|-----|---------|
| 价值 | 价格围绕价值波动 | 价值投资 |
| 周期 | 万物皆有周期 | 周期投资、大类资产轮动 |
| 规则 | 规则的可兑现性 | 套利、可转债、打新 |

### 投资的"三个知道"

| 知道程度 | 确定性 | 操作建议 |
|---------|-------|---------|
| 三者都知道 | 很高 | 可以重仓 |
| 知道两个 | 较高 | 中等仓位 |
| 知道一个 | 一般 | 轻仓试水 |
| 三者都不知道 | 很低 | 不操作 |

### 股票类型与预期管理

| 类型 | 特征 | 预期收益 | 操作方式 |
|-----|-----|---------|---------|
| 缓慢增长型 | 增速个位数，分红稳定 | 10%左右 | 做防守、资金池 |
| 稳定增长型 | 增速10%-15% | 15%-20% | 长期持有 |
| 快速增长型 | 增速20%以上 | 2-10倍 | 主动追风口 |
| 周期型 | 受宏观、供需影响 | 2倍或腰斩 | 景气低点埋伏 |
| 困境反转型 | 经营困难，股价便宜 | 2-3倍或归零 | 判断能否反转 |
| 隐匿资产型 | 隐藏大量资产 | 取决于变现 | 信息灵通时埋伏 |
