# A股交易策略技能集

## 策略1: MACD底背离 + 零轴下二次金叉

### 核心定义
- **第一脚**：跌出反抽
- **第二脚**：回踩验底
- **水下二次金叉**：验底后多头首次重新组织反攻

### 结构识别（按顺序检查）
1. 确认有前期下跌（没有明显下跌不讨论底背离）
2. 确认第一脚（下跌后第一次止跌与反抽，MACD第一次修复或金叉尝试）
3. 确认第二脚（反抽后再次回落到低位区域，形成二次试底）
4. 确认"第二脚变虚"（DIF低点抬高，或绿柱缩短，或第二次金叉位置高于第一次）

### 三档决策

**A. 上观察名单**（只跟踪，不急着买）
- 满足多数特征但尚未出现明确二次金叉或价格确认
- 标记观察价位：第二脚低点、短压位、前高压力
- 等待触发：水下二次金叉 + 1~3根K线拐头确认

**B. 可试错出手**（轻仓先手）
必须同时看到：
- 第二脚明显"变虚"（背离更清楚）
- DIF上穿DEA形成第二次金叉且仍在零轴下
- 二次金叉位置优于第一次（优先加分项）
- 金叉后价格出现最小确认（站回短均线/突破微平台/低点不再跌穿）
- 仓位：先手轻仓（10%~30%）
- 止损：设在第二脚低点下方（结构失效位）

**C. 必须放弃**（直接过滤）
任一命中即可放弃：
- 没有前期下跌，仅震荡噪音
- 第二脚回踩时MACD反而更弱
- 两次金叉中途已上破零轴再回落
- 金叉后迅速死叉或1~2天内跌破第二脚低点
- 上方套牢压力太近，仅够弱反弹空间
- 大盘/板块处于明显主跌且无共振修复

### 盘中检查单
1. 前面是否有一段像样下跌？
2. 第一脚后是否出现过反抽？
3. 是否已形成第二脚回踩到低位区？
4. 第二脚时DIF低点是否高于第一脚？
5. 绿柱是否明显缩短？
6. 是否出现零轴下第二次金叉？
7. 第二次金叉位置是否高于第一次？
8. 金叉后1~3根K线是否拐头并站回短均线？
9. 上方最近压力位是否过近（盈亏比不足）？
10. 失效位是否可承受？

判定：7条以上可进入试错评估；5~6条仅观察；4条及以下放弃。

## 策略2: MACD趋势共振选股

### 核心原则
**均线定方向，MACD定节奏。先看均线，后看MACD。先定方向，再找节奏。**

### 工作流

**Step 1: 均线定方向（硬过滤）**
- 60日线向上 + 收盘价在60日线上方 → 趋势合格
- 60日线走平或粘合 → 仅观察
- 60日线向下 + 收盘价在60日线下方 → 直接剔除

**Step 2: MACD定节奏**
优先级从高到低：
1. MACD位于0轴上方金叉
2. 红柱缩短后重新放大
3. DIF/DEA同步向上
4. 60分钟MACD与日线同向

降级条件：
- 日线MACD在0轴下方 → 仅观察，不列主买入候选
- 明显顶背离 → 降级或移出
- 金叉发生在下跌趋势中 → 只视为反弹

**Step 3: 四档候选分级**
- **A级**：趋势与节奏强共振（60日线向上+股价站上60日线+日线MACD在0轴上方+金叉/红柱二次放大+60分钟同步）→ EXECUTE
- **B级**：趋势对，节奏刚转强 → LIGHT（轻仓试错）
- **C级**：趋势尚可，但节奏矛盾 → OBSERVE
- **D级**：直接回避 → AVOID

### 评分框架（100分）
- 趋势方向 40分（60日线方向20+股价位置10+均线结构10）
- MACD节奏 35分（0轴上方15+金叉/红柱10+60分钟同步10）
- 板块与市场环境 15分
- 风控与事件清洁度 10分

映射：85-100 EXECUTE / 70-84 LIGHT / 55-69 OBSERVE / <55 AVOID

### 买点设计（条件触发式）
- 突破近5~10日平台高点
- 回踩20日/60日均线后企稳再上
- 日线趋势向上，60分钟MACD金叉共振
- 放量上破昨高/阶段高

每次必须给：触发条件 + 止损位 + 失效条件

### 卖点规则
优先减仓信号：
- 趋势未坏，但MACD顶背离
- 红柱持续缩短，动能衰减
- 60分钟先死叉，日线跟随转弱

直接离场信号：
- 股价有效跌破60日线
- 日线MACD下破0轴，且趋势同步转差
- 突破失败并放量回落

## 策略3: 退哥短线交易体系

### 市场环境判断（总开关）
先判断今天是否允许激进短线、仅允许回调确认，还是应该空仓。

### 场景地图
1. **趋势延续**: 处理趋势延续、回踩均线、缩量整理后再起
2. **涨停回调**: 处理涨停后整理结构（三阴不破阳、揉搓线、缩倍量回调）
3. **连板接力**: 处理一进二、二进三等高风险接力
4. **洗盘突破**: 处理黄金坑、假跌破、极度缩量后放量突破

### 标准输出模板
1. 当前市场环境
2. 今日允许使用的场景模块
3. 候选池分级
4. 当前结构类型
5. 触发条件
6. 失效条件
7. 卖出观察点
8. 仓位建议
9. 明确回避原因

### 仓位纪律
- 仓位等级：重仓/半仓/轻仓/试错/空仓
- 没有触发，不算买点
- 市场环境是总开关，环境不支持时不强行升级结论
- 同一标的同时命中多个场景，优先保留风险更低、定义更清晰的场景

### 统一约束
- 所有结论写成"条件 / 风险 / 失效"
- 不给"必涨"语言，只给条件、概率和纪律
- 系统性弱市中默认降低仓位与预期，只做快进快出或放弃

## 策略4: 主板多波段防御型

### 策略定位
在A股主板高流动性池内按趋势回踩（trend_pullback）产出买入候选与持仓卖出信号。

### 选股范围
- 从主板高流动性股票中取前N只构成当日股票池
- 默认参数：均线快慢线、回踩幅度、RSI区间、离场RSI

### 两层过滤
1. **成本过滤**：估算往返交易成本，只有 edge_after_cost > 0 的候选才进入最终买入列表
2. **鲁棒性过滤**：在参数邻域内计算入场一致性比率，低于阈值的候选被过滤

### 买入参考（两组）
- `from_previous_day_close`：上一根已收盘日线满足入场条件（更贴近事前计划）
- `from_last_close`：最新一根日线也满足入场条件（偏形态展示）

### 卖出参考
对持仓代码，若最新日线满足出场条件（破慢线或RSI过高），列入卖出参考。

## 风险纪律

- 背离是预警不是保证反转；若无价格确认，优先等待
- 不把"图形像双底"当买点，把"第二脚是否变虚 + 金叉后是否确认"当买点
- 一旦跌破第二脚低点，按原逻辑视为失效，优先执行止损
- 均线强、MACD弱：先观察节奏修复，不急着追
- MACD强、均线弱：按反弹看，不按主升看
- 个股强、板块弱：降低仓位与预期
- 信号漂亮但量能不确认：不升级评级
- 任何关键数据缺失：明确低置信，不输出强结论
