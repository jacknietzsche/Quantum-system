# 海龟交易法则 - 可执行决策技能手册

> 来源：柯蒂斯·费思《海龟交易法则》
> 适用对象：趋势跟踪型交易者、系统化交易者
> 核心定位：完整的机械化趋势跟踪交易系统

## 思维链示例（Thinking Chain）

### 案例一：判断是否应该入场做多（系统1-短线系统）

**场景**：用户问"这只股票突破了20日高点，可以买入吗？"

**思考步骤**：

```
第一步：检查突破有效性（确认信号）
    → 价格是否突破了过去20日最高点？（唐奇安通道上轨）
    → 突破当日收盘价是否高于20日最高点？（收盘确认原则）
    → 检查：是否出现反向突破信号（如跌破10日低点）？
    → "不要试图预测趋势，而是跟随趋势"
    → 关键原则：只在收盘后确认突破有效，避免盘中假突破

第二步：计算N值（ATR）和仓位大小（风险控制核心）
    → 计算真实波动幅度(TR)：
      TR = Max(当日最高价-当日最低价, |当日最高价-昨日收盘价|, |当日最低价-昨日收盘价|)
    → 计算N值（20日ATR）：
      N = (前19日TR总和 + 当日TR) / 20
    → 计算单位仓位（Unit）：
      单位仓位 = (账户资金 × 1%) / N
    → 举例：账户100万美元，N值=0.5美元，则单位仓位 = 10,000 / 0.5 = 20,000股
    → "保护本金是第一要务，盈利是第二目标"

第三步：检查相关性（分散风险）
    → 与现有持仓的相关性是否 < 0.7？（使用60日价格相关系数）
    → 高度相关品种（>0.7）总仓位 ≤ 正常仓位的50%
    → 单一板块持仓 ≤ 总仓位的25%
    → "分散投资降低风险"

第四步：设置止损（风险边界）
    → 初始止损位 = 入场价 - 2N（2倍ATR）
    → 止损金额 = 2N × 单位仓位数量 = 账户资金的2%
    → 举例：入场价100元，N=2元，止损位=96元，每单位风险=4元×2500股=10,000元（1%账户资金）
    → "亏损是趋势跟踪的必然成本"

第五步：执行建仓（系统化执行）
    → 首次建仓1个单位（按计算的单位仓位）
    → 建仓价格 = 突破20日最高价时的收盘价
    → 记录：入场日期、入场价格、N值、止损位、单位数量
    → "所有交易规则必须量化、可执行"

怀疑点：
    - 这是真突破还是假突破？（等待收盘确认，不预测）
    - 是否在震荡市中？（系统1在震荡市会频繁止损，这是必然成本）
    - 是否因为连续亏损而犹豫？（保持系统一致性，历史上海龟曾连续亏损10次以上）
    - 是否想减少仓位？（必须严格按照1%风险计算，不能随意调整）

最终决策关键：
    → 突破确认 + 仓位计算达标 + 相关性检查通过 = 入场
    → 严格执行止损，绝不移动止损位至亏损区域
    → 否则，等待下一个信号
```

### 案例二：加仓管理（金字塔加仓法）

**场景**：持仓已盈利，是否应该加仓？

**思考步骤**：

```
第一步：检查加仓条件（必须全部满足）
    → 条件1：当前持仓已盈利 ≥ 0.5N（价格向有利方向移动0.5个ATR）
    → 条件2：当前持仓单位数 < 4个单位（单一品种最大4单位）
    → 条件3：总持仓风险 ≤ 账户资金的10%
    → 条件4：趋势仍然有效（未跌破10日低点-系统1）

第二步：计算加仓价格和数量
    → 加仓价格 = 前一次入场价格 + 0.5N
    → 加仓数量 = 1个单位（与首次建仓相同计算方式）
    → 举例：首次入场100元，N=2元
      - 第1次加仓价格 = 100 + 0.5×2 = 101元
      - 第2次加仓价格 = 101 + 0.5×2 = 102元
      - 第3次加仓价格 = 102 + 0.5×2 = 103元

第三步：设置新单位的止损
    → 每个单位有独立的止损位：该单位入场价 - 2N
    → 单位1止损：100 - 4 = 96元
    → 单位2止损：101 - 4 = 97元
    → 单位3止损：102 - 4 = 98元
    → 单位4止损：103 - 4 = 99元

第四步：更新整体止损位（移动止损）
    → 整体止损位 = 所有单位中最高的止损位
    → 举例：当第2个单位建仓后，整体止损上移至97元
    → 关键原则：止损位永远不上移至亏损区域（即不低于最初入场价）

第五步：记录和监控
    → 记录每个单位的入场价、止损位、加仓时间
    → 每日检查：是否触及止损？是否达到加仓条件？
    → 当价格向有利方向移动1N时，将所有止损位上移0.5N

禁忌检查：
    - ❌ 绝不在亏损时加仓（摊低成本是致命错误）
    - ❌ 绝不一次性加满4个单位（必须分批）
    - ❌ 绝不因为"感觉好"而提前加仓（严格按0.5N间隔）

最终决策：
    → 所有条件满足 = 执行加仓
    → 任一条件不满足 = 持有现有仓位，等待下一个信号
```

### 案例三：出场决策（止盈与止损）

**场景**：持仓出现反向信号，是否应该平仓？

**思考步骤**：

```
第一步：检查止损条件（硬性规则）
    → 价格是否触及任何单位的止损位？
    → 如果是，立即平仓该单位，不犹豫、不期待反弹
    → 止损是保护本金的最后防线，必须机械执行
    → "永远不要移动止损位至亏损区域"

第二步：检查止盈条件（系统1-短线）
    → 价格是否跌破过去10日最低点？（唐奇安通道下轨）
    → 如果是，平掉所有单位，趋势可能结束
    → 收盘确认原则：等待收盘价跌破10日低点

第三步：检查止盈条件（系统2-长线，可选）
    → 价格是否跌破过去20日最低点？
    → 系统2更保守，持仓时间更长，但回撤也更大
    → 同一品种不能同时使用两个系统

第四步：检查反向突破信号
    → 是否出现反向突破（如做空突破20日低点）？
    → 如果是，平掉多头仓位，可考虑建立空头仓位（如规则允许）

第五步：心理检查
    → 是否因为"想保本"而想提前出场？（违背系统）
    → 是否因为"盈利足够多"而想出场？（让利润奔跑）
    → 是否因为"害怕回撤"而想出场？（接受回撤是趋势跟踪的成本）

出场执行：
    → 止损触发：立即市价平仓
    → 止盈触发：收盘确认后，下一交易日开盘平仓
    → 记录：出场日期、出场价格、盈亏金额、盈亏原因

关键原则：
    → 小亏损 + 小盈利 + 大盈利 = 长期盈利
    → 避免：大亏损（不止损）+ 小盈利（过早止盈）
```

### 案例四：完整交易流程示例（黄金期货）

**具体案例**：1983年海龟交易黄金期货

```
【背景设定】
- 账户资金：100万美元
- 交易标的：黄金期货（COMEX）
- 系统：系统1（20日突破入场，10日突破出场）
- 当前日期：假设为1983年某月

【第一步：计算N值（ATR）】
过去20日数据（简化示例）：
日期    最高价  最低价  收盘价  TR计算
Day1    450     445     448     5
Day2    452     447     451     5
...（中间省略）...
Day20   465     458     463     7

N = (5+5+...+7) / 20 = 6美元/盎司

【第二步：计算单位仓位】
- 每手黄金期货 = 100盎司
- 单位风险 = 账户资金 × 1% = 10,000美元
- 每单位止损金额 = 2N × 每手数量 = 2×6×100 = 1,200美元
- 单位仓位 = 10,000 / 1,200 ≈ 8手（取整）

【第三步：等待突破信号】
- 过去20日最高价 = 465美元
- 今日价格突破465美元，收盘价468美元
- 突破确认：收盘高于465美元，信号有效

【第四步：首次建仓】
- 建仓价格：468美元（收盘价）
- 建仓数量：8手
- 初始止损：468 - 2×6 = 456美元
- 止损金额：若触发，亏损 = (468-456)×8×100 = 9,600美元（约1%账户资金）

【第五步：加仓过程】
价格走势：
Day1    入场    468美元    持仓8手    止损456美元
Day5    价格涨至471美元（上涨0.5N=3美元）
        → 第1次加仓：471美元，加仓8手
        → 单位1止损：456美元
        → 单位2止损：471-12=459美元
        → 整体止损：459美元（最高止损位）
        
Day12   价格涨至474美元（再涨0.5N）
        → 第2次加仓：474美元，加仓8手
        → 单位3止损：474-12=462美元
        → 整体止损：462美元
        
Day18   价格涨至477美元（再涨0.5N）
        → 第3次加仓：477美元，加仓8手
        → 单位4止损：477-12=465美元
        → 整体止损：465美元
        → 已达最大4个单位，不再加仓

【第六步：移动止损】
Day25   价格涨至485美元（较最后加仓价涨1N=6美元）
        → 将所有止损位上移0.5N=3美元
        → 单位1止损：456+3=459美元（但低于入场价，保持456美元）
        → 单位2止损：459+3=462美元
        → 单位3止损：462+3=465美元
        → 单位4止损：465+3=468美元
        → 整体止损：468美元

【第七步：出场】
Day35   价格跌至470美元，跌破过去10日最低点
        → 止盈信号触发
        → 下一交易日开盘平仓所有32手（4单位×8手）
        → 平均出场价约470美元

【盈亏计算】
单位1：468→470，盈利2美元×8手×100 = 1,600美元
单位2：471→470，亏损1美元×8手×100 = -800美元
单位3：474→470，亏损4美元×8手×100 = -3,200美元
单位4：477→470，亏损7美元×8手×100 = -5,600美元
总盈亏：-8,000美元（-0.8%账户资金）

【复盘】
虽然这笔交易最终亏损，但：
1. 严格执行了系统规则
2. 单笔风险控制在1%以内
3. 总亏损仅0.8%，在可接受范围内
4. 这是趋势跟踪的必然成本，等待下一个趋势
```

### 案例五：纪律执行检查清单

**场景**：连续亏损后，是否应该继续执行系统？

```
【心理状态检查】
□ 是否因为连续亏损而想修改系统参数？（禁止）
□ 是否因为连续亏损而想减少仓位？（禁止，除非达到回撤阈值）
□ 是否因为连续亏损而想跳过下一个信号？（禁止）
□ 是否因为"这次不一样"而想主观判断？（禁止）

【系统一致性检查】
□ 是否所有入场都严格按照突破规则？
□ 是否所有止损都严格执行？
□ 是否所有加仓都满足0.5N间隔？
□ 是否所有出场都按10日/20日低点规则？

【风险控制检查】
□ 单笔风险是否 ≤ 1%？
□ 单一品种是否 ≤ 4个单位？
□ 总风险是否 ≤ 10%？
□ 高度相关品种是否已降低仓位？

【回撤管理规则】
当账户回撤达到：
- 10%回撤：正常执行，保持当前仓位
- 15%回撤：降低仓位至50%（即单位风险降至0.5%）
- 20%回撤：降低仓位至25%（即单位风险降至0.25%）
- 25%回撤：停止交易，复盘系统

【历史数据回顾】
- 海龟系统历史上曾经历连续10-15笔亏损
- 最大回撤通常在20-30%范围内
- 一年的盈利可能集中在2-3次大趋势中
- 80%的交易可能是小亏或小赚

【最终决策】
如果系统规则被严格执行：
→ 继续执行，不要改变
→ 降低仓位（如达到回撤阈值）
→ 连续亏损5笔后，强制休息1周

如果系统规则未被严格执行：
→ 停止交易，复盘问题
→ 回到模拟账户练习
→ 解决心理问题后再实盘
```

## 1. 核心哲学与基本原则

### 1.1 市场世界观

**原则1：市场以趋势方式运动，趋势是朋友**
- 价格以趋势方式运动，趋势一旦形成，大概率会持续
- 不要试图预测趋势，而是跟随趋势
- 核心地位：这是海龟系统的根基，所有交易决策都建立在趋势存在的前提下

**原则2：风险控制优先于盈利追求**
- 单笔交易风险不超过账户的2%
- 保护本金是第一要务，盈利是第二目标
- 核心地位：这是海龟能够长期存活的关键，没有风控，再高的胜率也会归零

**原则3：系统化交易优于主观判断**
- 所有交易规则必须量化、可执行
- 消除情绪干扰，严格执行系统信号
- 核心地位：这是海龟法则区别于普通交易者的核心优势

**原则4：分散投资降低风险**
- 同时跟踪多个市场，捕捉不同品种的趋势
- 单一品种仓位受限，避免集中风险
- 核心地位：这是实现长期稳定收益的基础

**原则5：接受亏损是交易的一部分**
- 亏损是趋势跟踪的必然成本
- 不要因为连续亏损而改变系统
- 核心地位：这是保持系统一致性的心理基础

**原则6：海龟法则的核心是突破系统**
- 价格突破一定周期的高低点时入场
- 使用唐奇安通道（Donchian Channel）作为基础
- 核心地位：这是具体的入场信号来源

## 2. 选股/标的决策树

### 2.1 标的选择流程

```
第一步：检查市场流动性
    ↓ 日均成交量 > 系统要求的最小值
    ↓ 是 → 进入第二步
    ↓ 否 → 排除该标的

第二步：检查波动性（ATR）
    ↓ ATR > 系统设定的最小波动阈值
    ↓ 是 → 进入第三步
    ↓ 否 → 排除该标的

第三步：检查相关性
    ↓ 与已有持仓的相关性 < 0.7
    ↓ 是 → 进入第四步
    ↓ 否 → 降低该标的仓位权重

第四步：检查趋势状态
    ↓ 价格突破20日/55日/60日高点（做多）或低点（做空）
    ↓ 是 → 触发交易信号
    ↓ 否 → 继续观察，不入场
```

### 2.2 硬性指标清单

| 指标类型 | 具体要求 | 检查方式 |
|---------|---------|---------|
| 流动性 | 日均成交量足够支撑建仓和平仓 | 查看过去20日平均成交量 |
| 波动性 | ATR(20日) > 账户资金的0.5% | 计算ATR并与阈值比较 |
| 相关性 | 与现有持仓相关系数 < 0.7 | 计算60日价格相关系数 |
| 趋势强度 | 突破N日高低点 | 检查是否突破20/55/60日极值 |

### 2.3 一票否决的红线清单

- ❌ 流动性不足：日均成交量低于系统要求的最小值
- ❌ 波动性过低：ATR低于账户资金的0.3%
- ❌ 相关性过高：与现有持仓相关性 > 0.9
- ❌ 价格异常：出现涨跌停板或交易中断
- ❌ 基本面恶化：出现重大负面消息（如退市风险）

## 3. 择时与买卖点判断规则

### 3.1 买入条件（做多）

**条件1：突破入场**
- 当价格突破过去20日最高点时，建立第一个头寸单位
- 当价格突破过去55日最高点时，建立全部头寸单位（更保守系统）
- 当价格突破过去60日最高点时，建立全部头寸单位（更激进系统）

**条件2：加仓条件**
- 每盈利0.5个ATR，加仓一个单位
- 最多加仓4个单位（即总仓位 = 4 × 基础仓位）
- 加仓价格 = 前一次入场价格 + 0.5 × ATR(20)

**条件3：确认信号**
- 突破当日收盘价确认突破有效
- 如果当日收盘回落至突破点下方，则信号无效

### 3.2 卖出条件（止盈与止损）

**止损条件：**
- **硬止损**：入场价格 - 2 × ATR(20)
- **移动止损**：持有期间，止损位随价格上涨而上移
  - 每上涨1个ATR，止损上移0.5个ATR
  - 止损位永远不上移至亏损区域

**止盈条件：**
- **系统1（短线）**：价格跌破过去10日最低点时平仓
- **系统2（长线）**：价格跌破过去20日最低点时平仓
- **反向突破**：出现反向突破信号时平仓

**量化标准：**
```
做多止损价 = 入场价 - 2 × ATR(20)
做多止盈价（系统1）= 过去10日最低价
做多止盈价（系统2）= 过去20日最低价

做空止损价 = 入场价 + 2 × ATR(20)
做空止盈价（系统1）= 过去10日最高价
做空止盈价（系统2）= 过去20日最高价
```

### 3.3 仓位管理规则

**基础仓位计算：**
```
单位仓位 = (账户资金 × 1%) / (2 × ATR(20))
```

**仓位分配原则：**
- 每个品种最大持仓 = 4个单位
- 每个方向（多/空）最大持仓 = 12个单位
- 总仓位不超过账户资金的50%

**建仓方式：**
- 采用分批建仓，而非一次性满仓
- 首次建仓1个单位
- 每盈利0.5个ATR，加仓1个单位
- 最多加仓至4个单位

## 4. 风险控制与心态纪律

### 4.1 风控铁律

| 规则 | 具体要求 | 违反后果 |
|-----|---------|---------|
| 单笔风险限制 | 单笔交易最大亏损 ≤ 账户资金的2% | 立即减仓或平仓 |
| 总风险限制 | 所有持仓总风险 ≤ 账户资金的10% | 停止新开仓 |
| 相关性限制 | 高度相关品种总仓位 ≤ 正常仓位的50% | 降低相关品种仓位 |
| 连续亏损限制 | 连续亏损5笔后，暂停交易1周 | 强制休息，复盘系统 |
| 单日亏损限制 | 单日亏损 ≤ 账户资金的5% | 当日停止交易 |

### 4.2 心理建设方法

**应对回撤：**
- 接受回撤是趋势跟踪的必然成本
- 最大回撤预期：20%-30%是正常范围
- 当回撤达到15%时，降低仓位至50%
- 当回撤达到25%时，降低仓位至25%

**情绪管理：**
- 每日交易前，回顾交易规则
- 出现亏损时，不急于翻本，等待下一个信号
- 出现盈利时，不急于加仓，严格按系统执行
- 连续盈利后，保持警惕，避免过度自信

### 4.3 禁忌行为清单

- ❌ 不执行止损：永远不要移动止损位至亏损区域
- ❌ 过度交易：不要在非信号出现时入场
- ❌ 预测市场：不要试图预测趋势结束，等待系统信号
- ❌ 修改系统：不要在亏损期间修改系统参数
- ❌ 集中持仓：不要将超过20%的资金投入单一品种
- ❌ 逆势操作：不要在趋势明确时反向操作
- ❌ 情绪化交易：不要在愤怒、恐惧或贪婪时做决策

## 5. 作者理论的适用边界与局限性

### 5.1 适用市场环境

**最适合的市场：**
- ✅ 强趋势市场：趋势明确且持续时间长
- ✅ 高波动性市场：ATR较大，有足够利润空间
- ✅ 流动性充足市场：能够顺利进出场

**不适合的市场：**
- ❌ 震荡市：价格在区间内波动，频繁触发止损
- ❌ 低波动性市场：利润空间不足，交易成本占比过高
- ❌ 黑天鹅事件：市场出现极端波动，系统无法应对

### 5.2 对投资者的要求

**知识要求：**
- 理解趋势跟踪的基本原理
- 掌握ATR、移动平均线等技术指标的计算和应用
- 了解期货、外汇等杠杆市场的交易规则

**性格要求：**
- 能够严格执行系统信号
- 能够接受连续亏损而不改变系统
- 能够承受20%-30%的回撤
- 有耐心，能够等待趋势形成

**资金要求：**
- 建议账户资金 ≥ 10万美元（期货市场）
- 能够承受至少50%的回撤而不影响生活
- 有稳定的资金来源，不需要从账户中提取资金

### 5.3 方法盲点

**作者承认的局限：**
1. **震荡市表现差**：在无明显趋势的市场中，系统会频繁触发止损，导致连续亏损
2. **入场滞后**：突破系统入场较晚，可能错过趋势初期利润
3. **假突破风险**：价格突破后回落，触发止损
4. **参数敏感性**：不同参数组合可能导致截然不同的结果

**实践中的问题：**
1. **心理压力大**：连续亏损期可能持续数月，对心理承受力要求极高
2. **资金曲线波动大**：收益分布不均匀，可能一年无收益，一年赚翻倍
3. **市场结构变化**：现代市场算法交易增多，传统突破系统效果可能下降

## 6. 可定制化问答语料库

### Q1：现在还能买吗？

**A1（基于海龟法则）：**

> "不要试图预测趋势，而是跟随趋势"

如果当前价格突破了过去20日（或55日/60日）的最高点，且满足以下条件，则可以考虑买入：

1. ✅ 该品种流动性充足，日均成交量达标
2. ✅ ATR(20) > 账户资金的0.5%
3. ✅ 与现有持仓相关性 < 0.7
4. ✅ 突破当日收盘价确认突破有效

**如果满足上述条件：**
- 建立第一个单位仓位，仓位大小 = (账户资金 × 1%) / (2 × ATR)
- 设置止损：入场价 - 2 × ATR
- 设置止盈：跌破过去10日（或20日）最低价时平仓

**如果不满足上述条件：**
- 等待下一个突破信号
- 不要追涨，不要预测突破

---

### Q2：被深套了怎么办？

**A2（基于海龟法则）：**

> "亏损是趋势跟踪的必然成本"

**第一步：检查止损位是否被触发**
- 如果价格已经触及止损位（入场价 - 2 × ATR），必须立即平仓，不要犹豫
- 止损是保护本金的最后防线，不执行止损是交易的大忌

**第二步：如果尚未触及止损**
- 检查是否满足继续持有条件：
  - 价格是否仍高于过去10日（或20日）最低价？
  - 趋势是否仍然向上？
  - 是否出现反向突破信号？

**第三步：决策**
- 如果趋势仍然向上，继续持有，等待系统止盈信号
- 如果出现反向突破信号，立即平仓
- 不要因为亏损而移动止损位，这是禁忌

**心理建设：**
- 接受这笔亏损是趋势跟踪的成本
- 复盘这笔交易，检查是否严格执行了系统
- 准备迎接下一个交易信号

---

### Q3：这只股票基本面很好但一直不涨，该持有还是卖出？

**A3（基于海龟法则）：**

> "趋势是朋友"

海龟法则**不考虑基本面**，只关注价格行为和趋势。

**决策依据：**

1. **检查趋势状态：**
   - 如果价格仍在上涨趋势中（高于移动平均线，不断创新高），继续持有
   - 如果价格跌破过去10日（或20日）最低价，卖出

2. **检查持仓成本：**
   - 如果当前价格低于你的入场价 - 2 × ATR，触发止损，卖出
   - 如果当前价格高于止损位，继续持有

3. **不要因基本面而违背系统：**
   - 即使基本面再好，如果价格跌破止损位，必须卖出
   - 即使基本面再差，如果趋势向上，继续持有

**结论：**
- 基本面不是海龟系统的决策依据
- 只根据价格行为和系统信号做决策
- 如果系统信号显示卖出，立即执行，不要犹豫

---

### Q4：连续亏损好几笔了，是不是系统失效了？

**A4（基于海龟法则）：**

> "不要因为连续亏损而改变系统"

**第一步：检查是否严格执行了系统**
- 是否所有交易都按照规则入场？
- 是否所有止损都严格执行？
- 是否有情绪化交易或随意修改规则？

**第二步：分析亏损原因**
- 是震荡市导致的正常亏损？
- 是假突破导致的止损？
- 是黑天鹅事件导致的极端波动？

**第三步：决策**

**如果是正常的市场波动：**
- 继续执行系统，不要修改参数
- 降低仓位至50%，减少风险暴露
- 连续亏损5笔后，强制休息1周

**如果是系统问题：**
- 检查参数是否仍然适用当前市场
- 检查品种选择是否需要调整
- 在模拟账户测试新参数，确认有效后再实盘

**重要提醒：**
- 不要在亏损期间随意修改系统
- 趋势跟踪系统必然有连续亏损期
- 历史上，海龟系统曾经历过连续10笔以上的亏损

---

### Q5：什么时候应该加仓？

**A5（基于海龟法则）：**

**加仓条件（必须同时满足）：**

1. **已有持仓盈利**：当前价格高于入场价至少0.5个ATR
2. **趋势仍然向上**：价格未跌破过去10日（或20日）最低价
3. **未达最大仓位**：当前持仓 < 4个单位
4. **风险可控**：加仓后总风险 ≤ 账户资金的10%

**加仓公式：**
```
加仓价格 = 前一次入场价格 + 0.5 × ATR(20)
加仓数量 = 1个单位
```

**加仓流程：**
1. 当价格达到加仓价格时，建立新单位
2. 为每个单位设置独立止损：该单位入场价 - 2 × ATR
3. 更新整体止损位：所有单位的最高止损价
4. 检查总风险，确保不超过账户资金的10%

**禁忌：**
- ❌ 不要在亏损时加仓（摊低成本）
- ❌ 不要一次性加满4个单位
- ❌ 不要在非系统信号时加仓

---

### Q6：如何设置止损位？

**A6（基于海龟法则）：**

**初始止损设置：**
```
做多止损价 = 入场价 - 2 × ATR(20)
做空止损价 = 入场价 + 2 × ATR(20)
```

**移动止损规则：**
- 每当价格上涨1个ATR，止损上移0.5个ATR
- 止损位永远不上移至亏损区域（即不低于入场价）
- 每个加仓单位有独立止损位

**示例：**
```
入场价：100元
ATR(20)：5元
初始止损：100 - 2×5 = 90元

价格上涨至105元（上涨1个ATR）：
止损上移至：90 + 0.5×5 = 92.5元

价格上涨至110元（上涨2个ATR）：
止损上移至：92.5 + 0.5×5 = 95元
```

**重要原则：**
- 止损位一旦设定，绝不向下移动
- 止损是保护本金的最后防线，必须严格执行
- 不要因为情绪而调整止损位
