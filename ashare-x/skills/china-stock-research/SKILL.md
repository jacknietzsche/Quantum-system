# A股深度研究框架

## 研究工作流

按以下顺序执行研究模块，每个模块独立输出，最后合并为统一研究框架。

### 模块1: 战略与业务转型 (strategy-business-transition)

分析公司从旧业务模式到新业务的转型进度。

**核心问题**:
- 公司是否在真正完成业务转型？
- 遗留资产是否仍在拖累业绩？
- 哪些里程碑可以证实或证伪管理层的战略叙事？

**分析步骤**:
1. 拉取招股书、最新年报/中报、近期重大公告
2. 建立业务模式变更、资本配置、融资行动、项目里程碑时间线
3. 识别旧业务、新业务和重叠期
4. 检验营收、毛利、资产、现金流是否随叙事迁移
5. 用转型记分卡评分

**输出**:
- `事实`: 业务历史、分部变化、资本配置、资产变化
- `解读`: 转型完成度、内部矛盾、可能瓶颈
- `待验证问题`: 仍需验证的内容及信息源
- `转型雷达`: 能力、客户结构、营收质量、轻资产进度、现金流转化

### 模块2: 业务分解与订单质量 (business-decomposition-order-quality)

拆解增长引擎，检验订单质量。

**核心问题**:
- 报告的增长是否有真实交付支撑？
- 客户是否健康？
- 现金回收是否匹配？

**分析步骤**:
1. 收集所有重大订单公告和近期报告
2. 构建产品、项目、客户、区域、合同金额、期限、交付阶段表
3. 对比订单增长与营收增长、毛利率、应收、合同资产、现金回收
4. 审查项目变更、取消、合同修订
5. 总结哪些增长是经常性的、一次性的、可能无法转化的

**输出**:
- `事实`: 分部结构、客户结构、项目列表、订单管线、收入确认方式
- `解读`: 订单质量、集中度风险、执行风险、交付可见性
- `Pipeline表`: 订单金额、阶段、预期转化、来源

### 模块3: 财务健康度 (financial-health)

诊断会计利润是否有真实现金流和韧性资产负债表支撑。

**核心问题**:
- 营收在增长但利润或现金流疲弱？
- 营运资本扩张速度超过销售？
- 债务、财务费用、担保、资本支出可能威胁资产负债表？

**分析步骤**:
1. 拉取最新年报、中报、季报
2. 构建三表视图：利润表、现金流量表、资产负债表
3. 聚焦现金转化、应收、合同资产、存货、资本支出、债务、财务费用、减值
4. 对比当前压力点与管理层解释
5. 评分流动性、杠杆和盈利质量

**输出**:
- `事实`: 关键科目、比率集、债务时间表、减值、营运资本趋势
- `解读`: 主要结构性问题、风险传导路径、可能断裂点
- `Health记分卡`: 盈利质量、现金转化、流动性、杠杆、资产质量

**关键指标**:
- ROE > 15%（持续5年优秀）
- 自由现金流/净利润 > 80%
- 资产负债率 < 50%
- 毛利率稳定或上升
- 现金转化率 > 70%

### 模块4: 行业竞争与护城河 (industry-competition-moat)

将公司置于真实行业结构中，检验是否有可防御的经济护城河。

**核心问题**:
- 公司的增长是否可持续？
- 声称的差异化是否真实？
- 哪些外部行业力量可能压缩回报？

**分析步骤**:
1. 定义价值链和公司在其中的确切位置
2. 从官方来源拉取行业政策和需求数据
3. 选择有来源支撑的同行组，比较产能、客户、利润率、业务模式
4. 应用护城河网格和五力结构
5. 标注公司在哪里捕获价值、哪里仍脆弱

**输出**:
- `事实`: 行业规模、政策顺逆风、同行位置、价值链角色
- `解读`: 护城河强度、结构性优势、可能压力点
- `价值链图`: 每环节标注强/中/弱捕获能力

**护城河类型**:
- 品牌力：消费者是否愿意为品牌支付溢价？
- 转换成本：客户切换到竞争对手的成本高吗？
- 网络效应：用户越多，产品越有价值？
- 成本优势：是否有结构性的成本优势？
- 政策壁垒：许可证、资质、数据、渠道

### 模块5: 风险预警与催化剂 (risk-warning-catalysts)

将静态研究转化为实时监控框架。

**分析步骤**:
1. 拉取最新公告，识别上次报告以来的变化
2. 按类别映射风险：执行、财务、治理、政策、客户、技术、诉讼
3. 按类别映射催化剂：订单、政策、融资、资产处置、产能利用率、利润率改善
4. 为每项附加阈值、预期证据来源和审查频率
5. 构建月度仪表盘和催化剂日历

**输出**:
- `事实`: 确认的风险、确认的催化剂、上次更新状态
- `解读`: 哪些因素对投资逻辑最重要及原因
- `Dashboard`: 指标、阈值、最新值、来源、下次检查日期

### 模块6: 估值与投资策略 (valuation-investment-strategy)

在事实基础完整后，构建情景化估值。

**核心原则**:
- 不在公开证据缺失时编造输入
- 使用情景分析而非虚假精度
- 将事实与判断和交易计划分开

**分析步骤**:
1. 拉取前五个模块的输出
2. 选择合适方法：同行倍数、SOTP、EV/EBITDA、PB、DCF、资产基础法
3. 定义情景表：营收、利润率、资本支出、产能利用率、资产负债表假设
4. 将每个假设链接到支撑来源或标记为分析估计
5. 产出价值区间、投资逻辑检查点和证伪触发器

**输出**:
- `事实`: 估值相关事实、同行组、资产基础、融资约束
- `解读`: 哪种方法最适合及原因
- `情景表`: 熊/基/牛，带关联假设
- `投资计划`: 建仓条件、止损条件、逻辑确认里程碑

## 不可协商规则

- 严格区分 `事实`、`解读` 和 `待验证问题`
- 每个关键事实和数字必须带可访问的来源链接
- 优先使用官方披露、监管机构和公开官方门户，而非媒体和评论
- 默认使用简体中文输出
- 不在证据薄弱时编造模式匹配；在 `待验证问题` 中标注不确定性
- 不产出无支撑的目标价或投资结论
- 不将模块输出合并为单层叙事；保持证据分层完整
